# 历史档案

这里保留设计原稿、旧实现说明、修订记要和复评包。内容按原作者写作时的版本保存；当前入口、代码职责与测试走法从[现行文档](../README.md)进入。

- [设计原稿（design）](design/)：世界设定、长篇剧情与美术方案、早期章节范围和剧情优化草案。
- [工程与迁移（engineering）](engineering/)：系统长文、旧测试协议、迁移清单与技术审计。
- [修订与复测（reviews）](reviews/)：阶段状态、厨房和开场修正、盲读对照、交互迭代账本。
- [网页原型](index-web-prototype.html)及旧打包文件：迁移对照资源。
- [历史复评包（bundles）](bundles/)：原归档文件与校验值。
