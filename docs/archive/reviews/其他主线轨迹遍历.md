## 重复运行

使用项目 Python 运行 `tools/testing/run_mainline_survey.py`。默认遍历整个其他主线计划，可重复指定 `--segment shaft` 等段落筛选；输出目录必须全新。启动器校验工程与真实宿主 PID，保留源文件哈希；运行错误归入 blocked。

采集后运行 `tools/testing/publish_mainline_survey.py <输出目录>`，校验截图 SHA256 与宿主 PID，再通过 MCP 自动追加每段检测及完成确认。段落闭环后调用评分 MCP 的 `render`，批量导出并检查链接。

快照保存在每个入口的 `entry.snapshot.json`。用现有快照启动入口传入该路径，可直接回到本次入口继续调查。
