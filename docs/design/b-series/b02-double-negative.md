# B02 · 双底片 The Double Negative

**一句话**：暗房里站着两个 Hale。一个是真的，守 Ochre 版手册；另一个是底片印出的负像，守的是**你的** Ivory 手册。你一犯禁看进光圈，影子就被吸走。按你自己的规则，你从此成了「假的」，于是守你规则的那一位会离你而去。

| 项 | 内容 |
|---|---|
| 房牌 | 暗房 Fixing Room（沿用 brief：`Your group shows up on an undeveloped negative.`） |
| 目标类型 | 辨认冒充者＋拒绝＋护送：带真 Hale 从画中门离开，把负像封进定影罐 |
| 期限 | 转鼓的落锤走到底（约 6–9 圈，视转速而定）后，显影带停在原地，画中门不再出现 |
| 失败的余波 | 如果带出的是负像，本局余下房间里，「Hale」会按 Ivory 镜像版行动：一份跨房间的规则怪谈 |
| 工具 | 毛毡：塞进调速风扇，转速固定，剂量变得可算。棘轮：锁住罐盖绞盘，封罐可以分两次完成 |

## 一、空间与巨物

圆形暗房直径 30 m，中央是直径 10 m、深 5 m 的定影罐，四周一圈石质环台。罐的石盖竖立在近侧绞盘上。远侧石墙上没有门。

| 构件 | 运动 | 改变的通行几何 |
|---|---|---|
| **暗箱转鼓**（巨物） | 12 m 高，悬在罐上方，靠落锤驱动、风扇调速；鼓缝透镜把整间房**倒像**投成一条 40° 宽的显影带，绕房扫转，每圈 60–110 s | 显影带里，投影出来的表面对「看画的人」是实体，被照到的真实石面对他们反而虚化 |
| **画中桥** | 竖立的罐盖经倒像投影，在远侧平躺着横跨罐口 | 只在显影带扫过罐口时存在。一旦放下罐盖封罐，桥的投影源就消失了 |
| **画中门** | 入口拱门的倒像，落在远侧空墙上 | 只在显影带扫到远墙时出现，是唯一的出口 |
| **罐内石阶** | 真实石阶，从环台下到罐底 | 只走石面的东西，只能沿这条路去追远侧的人 |

## 二、剂量场

| 量 | 定义 | 玩家怎么读 |
|---|---|---|
| 亮度 I | 由光圈拉杆决定。光圈与风扇叶片同轴：**开得越大越亮，转得也越慢** | 显影带的明度、扫过的速度 |
| 剂量 D | 每段连续受照 D += I·t^0.8（施瓦氏倒易律失效）；每次重新进入显影带，再加一次闪光项 | 皮肤逐渐银化：手背→脸→全身 |
| 转速漂移 | 定影液随时间升温，热气推动风扇，转鼓渐快；光圈也会改变转速 | 落锤的下降速度；带边扫过时的嗡声音高 |
| 结果 | 真 Hale 的 D ≥ 1 时被「定影」进画面，再也走不出投影面：你失去同伴。你的 D ≥ 1 时，会印出一个**你的负像** | 银化到全身前，有 40 tick 的预警 |

倒易律失效让直觉反过来：**多次短照比一次长照更伤**。想让 Hale 少挨剂量，就得开大光圈、让转鼓变慢，让他一次在带里走完长段，而不是追着快转的带一段段跳。但光圈越大，单位时间越亮，转速与升温又互相牵制，所以每圈的最优光圈只能看着银化程度现调。

## 三、三份手册

| 谁 | 规则（玩家可见文字 / 中文） | 在胜利路线上 |
|---|---|---|
| 队长 Ivory | `Never look into the aperture.` 勿看进光圈 | **必须违反**：只有看进光圈，你才能踩画中桥、进画中门 |
| | `Walk only on stone.` 只走石面 | **必须违反**：画中桥不是石头 |
| | `One who casts no shadow is false.` 没有影子的是假的 | **陷阱**：两个 Hale 都有影子，这条分辨不了任何东西 |
| | `Count heads before you seal the tank.` 封罐前点清人数 | **必须照做，但结论反直觉**：罐里要恰好数出「一个人」 |
| 真 Hale（Ochre 卡） | `Walk only on floor that is in the picture.` 只走画面里的地面 | 他只能在显影带里移动 |
| | `Never step into the dark.` 不进黑处 | 带一走，他就站住不动 |
| | `One who casts no image is false.` 不投出像的是假的 | 你看进光圈后仍然投像，他继续跟你 |
| | `Follow whoever first shows you yourself.` 谁先让你看见自己，就跟谁走 | 你要第一个领他进显影带，让他看见自己投在墙上的像 |
| 负像 | 守 **Ivory**（与你相同） | 只走石面；把「同伴」留在视线内；把没有影子的人当作假的 |

## 四、关键反转

| 现象 | 后果 |
|---|---|
| 你看进光圈 | 画面成为你的实地；你的影子被像吸走，直到你重新走进环台的油灯光圈才回来（显影带不算灯光） |
| 你失去影子 | 负像按 Ivory I-3 认定你是假的，转而把**另一个 Hale** 当作要留在视线内的同伴，去追他 |
| 真 Hale 踩画中桥过罐 | 负像只走石面，只能沿罐内石阶下到罐底，想从对面爬上去 |
| 负像下到罐底时 | 你在远侧放下罐盖：负像被封在罐里，画中桥也随之消失 |
| 封罐前点人数 | 罐里只有一个人形，就是负像。点人数这一步本身，就是最后一次辨认 |

## 五、从终局倒推

| 步 | 必须成立 | 为什么想不到 |
|---|---|---|
| **E** | 显影带扫到远墙时，你和真 Hale 穿过画中门，负像封在罐里 | 出口是一张投影，不是墙上的门 |
| E-1 | 穿门那一刻你必须仍「看得见画」 ⇐ 看进光圈后，一路避开环台的油灯光圈 | 你要躲开油灯，而真 Hale 不进黑处，两人只能在显影带里同步移动 |
| E-2 | 罐盖须在你们过桥**之后**、负像下罐**之后**放下 ⇐ 放盖会抹掉桥，所以绞盘在远侧 | 封罐和过桥在时间上互相排斥 |
| E-3 | 负像必须追着真 Hale 下罐 ⇐ 它已不把你当同伴 ⇐ 你没有影子 ⇐ 你看进了光圈 | 你的禁忌就是辨认工具：守你规则的那位，按你的规则抛弃了你 |
| E-4 | 真 Hale 必须跟你 ⇐ 你是第一个领他进带、让他看见自己的人 ⇐ 开局两 Hale 外观一致，你必须先认出谁是真的，才知道该领谁 | 用 Ivory 影子法测不出来；只有显影带里谁「不投像」才能分辨（Ochre 法） |
| E-5 | 真 Hale 在整个过程中 D < 1 ⇐ 每圈按银化程度现调光圈 | 倒易律失效，凭直觉会调错方向 |
| 开局 | 在灯光里观察，等第一圈显影带扫过，看谁在远墙上没有像 | — |

**伪终态与反例**：

| 玩家会试的路 | 结果 |
|---|---|
| 用影子法辨认，领一个 Hale 走 | 五五开；领错了，负像会一路跟你到画中门前，然后因为「只走石面」停在桥头。你若回头领它，就输了 |
| 不看光圈，沿石面环台绕到远侧 | 远墙没有门；画中门对你不是实体 |
| 早早放下罐盖封罐 | 画中桥消失，远侧再也到不了 |
| 先看光圈，再去领真 Hale | 你没有影子之后，负像去追真 Hale。若此时你还没成为「第一个让他看见自己的人」，它会贴在真 Hale 身边，在每次带扫过时挡在环台窄处 |
| 让真 Hale 追着快转的带一段段跳 | 闪光项叠加，他在半路被定影 |

## 六、白盒难点

两 Hale 的真假、风扇初始叶角和定影液初温都由种子决定，只能在实机里观察。剂量公式公开，但转速、升温和光圈三者耦合，没有闭式解；而且每次拉光圈，都会同时改变下一圈的时长与亮度。负像的行为是**你手册的忠实执行**，所以它对你的反应取决于你当下有没有影子，没法提前写成固定脚本。

## 七、实现入口

显影带与「投影即实体」沿用 A04 的光束遮断与假影；物态过滤沿用 A01。两个 Hale 共用英雄 GLB，负像只换材质（影子正常、不在投影里成像）。剂量模型按 B01 的做法，先写数值原型，测出可解率和固定动作带成功率，再建房。
