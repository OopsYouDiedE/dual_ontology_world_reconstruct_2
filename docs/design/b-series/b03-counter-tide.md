# B03 · 逆潮回廊 The Counter-Tide Cloister

**一句话**：泵房回廊里漂着一条巨型浮闸船，只有一次「逆潮」能把它抬到出口拱门的高度。逆潮来自你被严禁打开的旱档案室。你要带出的真图纸必须先被淹湿才会显出印章，而晾干它的，只能是那位守着晾纸盘寸步不离的 Ochre 同伴。

| 项 | 内容 |
|---|---|
| 房牌 | 泵房 Pump Archive（沿用 brief：`There are wet fingerprints on the inner face of the gauge glass.`） |
| 目标类型 | 把证物交到对的人手里＋存活到某个时相：逆潮峰值时，让同伴拿着已干的真图纸登上出口拱门 |
| 参与者 | 队长（Ivory）＋一名 Ochre 版同伴 |
| 期限 | 旱档案室这只「毕达哥拉斯杯」只翻一次；峰值约 40 s，错过就只剩撤退 |
| 工具 | 毛毡：吸干晾纸盘，晾干时间减半。棘轮：卡住浮船系缆，船停止摆扫，可以从容登船 |

## 一、空间与巨物

回廊方形，36 × 36 m。中庭是深水主池，四周两层拱廊：下层离地 1.5 m，上层 6 m。北侧地下是旱档案室，体积最大，由一道水闸隔开。出口拱门在西侧上层，门槛 +7.6 m，下面垂着一段 0.5 m 的绳梯。

| 构件 | 运动 | 改变的通行几何 |
|---|---|---|
| **浮闸船**（巨物） | 长 26 m、宽 6 m，船尾（西）系在中庭的枢轴上；甲板高度 = 水位 + 干舷 + 纵倾；船随水流绕枢轴摆扫 | 水位 <3 m 时，龙骨堵死下层涵洞；5–6 m 时，甲板接上南侧上层拱廊（死路，但能看见出口）；只有逆潮峰值、且船尾翘起时，甲板才接上西侧出口拱门。摆扫时会撞上拱廊柱，把站在柱间的人挤进水里 |
| **晾纸盘** | 固定在船头（东） | 正对东侧高窗。高窗是外窗，日光斑随本局的时刻移动 |
| **舱室** | 船中段 | 站在这里不影响纵倾 |
| **三池虹吸** | 屋顶水箱 → 主池 → 地窖，每级一条坦塔罗斯虹吸：水位到顶就起虹吸，降到进水口才断流；流量 ∝ √落差 | 起虹吸的那一池在主池里冲出射流，射流的合力推船摆向不同方位 |
| **旱档案室** | 打开水闸后，成为第四只池；它的排水口本身就是一只毕达哥拉斯杯：水满到暗藏的杯顶就一次性倒灌回主池 | 倒灌就是**逆潮**：主池涨到全局最高，并保持约 40 s |

## 二、力场：间歇虹吸三联振荡

三只池各自是一个弛豫振荡器，彼此串联；雨水从外面的落水管持续流入。水位序列近似周期，但对初始水位很敏感。玩家能动的只有每条虹吸顶上的**气阀**：开阀能提前打断正在运行的虹吸，或阻止它起虹吸。打断上游，往往让下游**提前**起虹吸，这一点很反直觉。主池水流的方向由此改变，船的摆扫也随之改变。

打开档案室水闸后，第四只池接入，整个振荡被重写：档案室灌满的速度取决于主池当时的水位，而主池水位又取决于三池的相位。所以逆潮何时到来，只能盯着档案室的水位玻璃看，没法预算。

| 可读仪器 | 读什么 |
|---|---|
| 每条虹吸的透明顶管 | 有没有在吸水、气泡多少 |
| 档案室水位玻璃 | 离暗藏的杯顶还有多远；玻璃内侧的湿指纹标出上一次翻杯时的水位线 |
| 船头指向 | 当前水流的合力 |
| 图纸的颜色与卷曲程度 | 晾干的进度 |
| 日光斑在甲板上的位置 | 随本局时刻移动（遵守「只有外窗引入时间光」的约定） |

## 三、两份手册

| 谁 | 规则（玩家可见文字 / 中文） | 在胜利路线上 |
|---|---|---|
| 队长 Ivory | `Drawings must be returned dry.` 图纸须干燥交回 | **陷阱**：档案室里干燥的图纸全是伪件 |
| | `Never open the sluice to the Dry Archive.` 勿开旱档案室水闸 | **必须违反**：只有它能带来逆潮 |

## 四、从终局倒推

| 步 | 必须成立 | 为什么想不到 |
|---|---|---|
| **E** | 逆潮峰值时，船尾甲板对齐出口门槛 +7.6 m；同伴双手捧着已干的真图纸跨进拱门，队长随后爬绳梯上去 | 出口要靠「涨水」才够得着，而涨水的源头是禁区 |
| E-1 | 船尾够高 ⇐ 峰值期间，船头有一个人、船尾没人（船尾 +0.4 m）。同伴在船头守盘；纸一干，他起身往船尾走，**队长同时跑到船头接替压舱**，否则船尾会随他的脚步一路沉下去 | 两个人的位置，就是这个巨物的配平 |
| E-2 | 队长最后离船时船尾已沉回 +7.2 m ⇐ 只有空着手的队长能爬 0.5 m 绳梯，捧图纸的同伴不能 | 出场顺序被能力差锁死：必须同伴先走 |
| E-3 | 图纸必须在峰值结束前晾干 ⇐ 晾纸盘要在日光斑里待够时间 ⇐ 用气阀改变水流，把船头摆进移动的光斑，同时不能把逆潮的相位推错 | 你在用水力场开一艘巨船，而光斑跟着真实时刻走 |
| E-4 | 晾的必须是**真**图纸 ⇐ 真图纸的印章是遇水显色的铁胆墨，只有先湿后干才看得出 ⇐ 它要被「从下面涨上来的水」打湿（O-3） ⇐ 开闸灌档案室时，它就在最下层抽屉里被淹 | 你要保护的档案，正是要被毁掉的东西 |
| E-5 | 要在杯翻之前把湿图纸从档案室取出、交给同伴 ⇐ 杯翻时还在室内，会被倒灌的水冲出去（扣 HP，图纸散失） | 取图时机由水位玻璃决定，不由你决定 |
| E-6 | 交给同伴，而不是自己处理 ⇐ 你的 I-3 会把湿图送回档案室的干抽屉 | 「把证物交到对的人手里」：对的人守的是另一版规则 |
| E-7 | 开闸后登船时船一定在动（违反 I-4）⇐ 只能在船舷擦过拱廊开口的那一刻跳上去 | 几何随水流时开时合 |
| 开局 | 观察三池振荡和船的摆扫规律；从档案室上层抽屉看出伪件（干、无印章），在最下层找到 `WET PROOF — DO NOT ISSUE` | — |

**伪终态与反例**：

| 玩家会试的路 | 结果 |
|---|---|
| 守 Ivory：带一张干图纸，不开闸 | 船最高只到 6 m，接上南侧拱廊，那里是死路；即使绕到出口，门槛的登记槽也会拒收伪件 |
| 开闸后自己晾图，或按 I-3 把湿图放进干抽屉 | 抽屉随档案室被淹，图纸化成纸浆 |
| 用屋顶虹吸的射流去淋湿真图 | 同伴按 O-3 拒绝晾它 |
| 峰值期间队长也站在船尾 | 船尾只到 +7.2 m，同伴跨不上去 |
| 图纸在峰值结束时还没干 | 同伴按 O-2 守在船头，你只能独自离开，图纸留在房里 |
| 不用气阀，听天由命 | 船头大部分时间偏离光斑，晾干时间不够；成功率取决于种子与本局时刻 |

## 五、白盒难点

三池的初始水位、落水管的雨量和本局时刻（决定日光斑位置）都随种子与运行状态变化。逆潮到来的时刻，由四池耦合的弛豫振荡决定，必须实测；船头在光斑里的累计时长，又取决于你在这段过程中每一次开关气阀。同伴的站位是规则驱动的，他的移动会实时改变纵倾，所以收尾的那十几秒只能看着船尾刻度现场配合。

## 六、实现入口

水力与相位历史沿用 Meniscus Court（A09）的模型与回放校验；虹吸的滞回、射流与浮船纵倾是新增部分。Ochre 的晾纸规则已在 [Rooms.gd](../../../scenes/rogue_crossing/Rooms.gd) 的版本表里。按 B01 的做法，先写数值原型：对种子与时刻的分布验证「每个种子都有解」，并测出固定动作带的成功率，然后再建房。
