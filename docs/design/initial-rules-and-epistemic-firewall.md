# 《沉睡学院》重构基准：认知防火墙、全院初期怪谈规则与同伴隐藏守则

> **文档状态**：已确认定稿（2026-11-28）  
> **适用范围**：全游戏主线、高难度类肉鸽循环、开场序列、随身手册、同伴行为 AI 及各偏翼局部关卡重构。  
> **核心铁律**：初期玩家可接触的一切文本、对白与 UI **只允许总结可观测的现象与规律，严禁泄露深层世界观本体**（禁止出现“源质”“十二条对赌契约”“恶魔”“四锚”“单实体锁”“双世界”“魔法隐藏”等底层术语）。

---

## 一、两级规则分层与认知防火墙

1. **全局初期层（随身持有 / 行为观测）**：覆盖整座孤岛学院、全部周目与三条结局线，不绑定单一章节或单关机关。分为：
   - **主角初期规则（8 条）**：客观、冷峻、纯物理/环境/空间级的学院安全守则；
   - **霍铎（Hale）隐藏规则（6 条）**：聚焦海岛边界与空间异常工作守则；**无完整文本供玩家阅读，玩家只能通过霍铎在 3D 实机中的反常举动反推其守则**。
2. **局部现场层（进房现捡）**：针对单个偏翼或肉鸽房牌的专属怪谈（如井区交接簿、B01 擒纵厅刻文、天文台晨钟铭牌），随探索在现场拾取，绝不混入初期全局规则本。
3. **深层本体层（开发真源，初期封禁）**：火山源质重气溶胶与神经认知拓印、被魔法隐藏区域的双世界折叠、地下四锚、无恶意高维代管者与《十二条对赌契约》。它负责在底层保证所有表层规律逻辑自洽，但绝不在开局剧透。

## 二、主角初期持有的怪谈规则列表（8 条 · 全院通用）

| 编号 | 规则主题 | 正式条文（玩家初期可见） | 底层真实原因（开发真源 · 严禁初期暴露） |
| :--- | :--- | :--- | :--- |
| **01** | **地雾** | 夜里，地面会飘起一层白雾，这是正常现象，无视即可，不要触碰；若白雾没过鞋面，立刻放下手中一切任务，前往高处； | 火山源质（重气溶胶）贴地沉降并按五阶段涨潮；浅层无害，没过鞋面即进入高浓度神经拓印/窒息危险线。 |
| **02** | **高精度仪器** | 本学院安装的仪器设备均为高精度仪器，在未遭受外力损坏状态下不可能出现工作异常。 | 反推锚点：当傅科摆、怀表、挂钟等仪器完好无损却读数失常时，意味着**坏的不是仪器，而是该空间或时间本身处于异常状态**。 |
| **03** | **重复走廊** | 本学院不存在两段前后相连且完全一致的走廊；若你发现眼前走廊与刚走过的那一段完全相同，不要继续前进，立刻原路退回，直至回到有明确编号的通道； | 地下四锚松动或局部折叠引发的空间拓扑循环；强行深入会脱离正常编号锚点并陷入闭环。 |
| **04** | **提灯焰色** | 本学院配发的煤油提灯正常燃烧时火焰呈暖黄色且垂直向上；若在无风室内火焰突然倒向一侧、或变为苍白色，不要试图调大灯芯，立刻盖灭提灯，原地待眼睛适应黑暗后再缓慢撤离； | 密闭空间内出现不可见的高浓度源质气囊或密度流；明火会剧烈扰动富集气溶胶并暴露热/光坐标，盖灭提灯可避免扰动与暴露。 |
| **05** | **多余的影子** | 单人仅持一盏提灯行进时，地面与墙面只会投下一道清晰的影子；若你在灯光下发现自己脚边多出第二道影子，不要回头，保持原有步速继续向前，直至走过下一处常明壁灯； | **高维无恶意代管者**（或处于模因盲区内的实体）正在身后经过。人类大脑屏蔽了其本体，但光线仍投出影子；**代管者本身无恶意，但凡人强行回头直视高维实体化截面会触发 `[数据删除]` 级认知过载**。保持步速经过常明壁灯即可安全错身。 |
| **06** | **玻璃倒影** | 入夜后，廊窗玻璃只会映出室内灯火与人影；若你在玻璃上看见自己的倒影动作慢了半拍、或映出房间里并不存在的人，不要观察任何玻璃，并立刻退出房间； | 附着在玻璃与彩窗表面的源质凝露产生延迟认知拓印（回放上一轮循环残影或映出模因盲区实体）；继续观察会导致意识被残影同步覆盖或直视未收敛的高维侧面。 |
| **07** | **自开的门** | 本学院所有铜制门闩均装有防风弹簧，绝不会自行弹开或反锁；若你转身时发现刚才亲手关紧的门已悄然敞开，不要再穿过那扇门，改道从其他通道绕行； | 高维实体（代管者）刚刚穿过该门留下未散去的高维尾迹与空间形变，或门后空间已发生拓扑置换；改道可避开尾迹并利用单实体锁特性绕行。 |
| **08** | **挂钟同停** | 院内各走廊的机械挂钟均与主钟楼同步运转；若你连续经过两个挂钟指针停在同一刻度的房间，不要再核对自己的怀表，立刻停止探索，寻找最近的值班室等待整点； | 局部时间滞留带（与主钟楼脱钩，向顺行性遗忘闭环坍缩）；在滞留区内强行掏出个人怀表对表，会导致个人时间基准被停滞刻度同化锁死。退回值班室听主钟楼整点报时方可重校准。 |

## 三、霍铎（Hale）的隐藏残缺规则列表（6 条 · 仅通过行为反推）

> **设计原则**：霍铎本人没有完整印刷文本，仅凭残缺记忆与外勤习惯行动。游戏内**绝不直接弹出下列条文**，而是通过其可辨识的 3D 动作与反应，让玩家自行观察、猜想并学会配合或利用。

| 编号 | 规则类别 | 隐藏守则内容（玩家不可直读） | 底层真实原理 | 玩家在 3D 场景中可见的霍铎行为 |
| :--- | :--- | :--- | :--- | :--- |
| **H1** | 仪器基准 | 大厅内的傅科摆，摆动周期为 7.0 秒（按大厅 12.24 m 摆长与标准重力 g = 9.80665 m/s² 精确计算取小数点后一位）。工作时，其必定经过中心。 | 补全主角规则 02 的定量标尺：周期非 7.0 秒说明时间流速/重力场畸变；摆迹绕开中心说明大厅正中存在空间曲率扭曲或不可见高维实体占位。 | 经过大厅傅科摆时，霍铎会低头默数怀表秒针，并紧盯摆锤是否掠过地面中心铜点；一旦周期不准或摆迹偏心，他会立刻神色凝重并调整行动路线。 |
| **H2** | 海岛边界 | 当听到汽笛或者海浪声时，不得观察任何窗户。 | **观察者效应的空间折叠**：本区域本质上被魔法隐藏在现实世界之外；听见外界汽笛或海浪声说明现实世界实体正经过隐藏区边界，此时观察窗户会触发观察者效应，导致**两个世界强行重叠**。 | 远处刚响起汽笛或明显海浪声，霍铎瞬间背对所有窗户（压低视线或蹲身遮眼），无论玩家如何呼唤都绝不向窗外张望，直至声响彻底消失。 |
| **H3** | 异常作业 | 可以在空间异常区记录数据，但不得对数据进行分析。 | 在高浓度源质/折叠空间内，机械抄录符号不会激活深层认知；一旦开始分析推导、试图建构意义，观察者意识会直接介入并触发认知反噬或异常坍缩。 | 在异常区内，霍铎只用铅笔机械抄录刻度与符号，若玩家在异常区内追问原因或试图讨论推论，他会立刻制止并示意退回正常走廊再谈。 |
| **H4** | 异常作业 | 在空间异常区取走物品，必须使用大小相近的物体取代原来的物品。 | 维持折叠/异常空间的几何体积占位稳态；直接取走留下空洞会触发异常空间检测到结构缺损，引发剧烈空间失稳或反扑。 | 玩家直接拿起异常区关键物品准备撤离时，霍铎会拦下或在原位放上一枚大小相近的随身物件（砖块、铜件、书本）占位，才肯一同离开。 |
| **H5** | 海岛边界 | 在窗台、连廊或海岸边发现带有外界近期日期、陌生邮戳或湿咸海盐味的物件，不得带入学院主楼。 | 双世界擦碰瞬间从外部现实世界“漏”进隐藏区的现实碎片；将其带入主楼会把外部现实坐标钉入隐藏区，诱发局部空间撕裂或双世界叠合。 | 遇到窗边潮湿的陌生信件、近期报纸或带海盐味的漂流物时，霍铎绝不徒手收起，也不会让玩家装进背包，而是用工具将其拨离主通道。 |
| **H6** | 异常作业 | 空间异常区作业必须在主钟楼整点鸣钟前撤回正常区域；若来不及撤离，立刻丢下手中工具贴墙静立，直至钟声结束。 | 整点钟声是隐藏区重新校准折叠边界的刷新节点；滞留异常区内跨过整点会被当成该区域的固有内容物一并卷入空间重排。 | 即使机关眼看就要解开，只要霍铎看表发现临近整点，便会立刻果断撤离；若来不及出门，则直接扔掉手中工具、死死贴墙静止不动直到钟声落定。 |

## 四、双向规则不对称与霍铎排查行为设计

玩家与霍铎并非“保姆带新人”，而是**双向规则盲区互补**：玩家靠观察霍铎习得 **H1–H6**，霍铎则缺少玩家手册中的 **04、05、07、08** 四条规则，排查时会按常人/外勤直觉踩雷，需要玩家及时干预救场。

| 霍铎缺失的规则 | 霍铎排查时的错误直觉（3–5 秒可视前摇 + 简短自言自语） | 玩家干预与未拦截后果 |
| :--- | :--- | :--- |
| **规则 04（提灯焰色）** | 进入不可见气囊，提灯火焰倒伏发白变暗；他误以为油量或灯芯问题，伸手去拧大灯芯（*“灯怎么暗了，我调大一点……”*）。 | 及时喊停并盖灭提灯摸黑撤离；未拦截则扰动源质层、引发局部剧烈雾潮/暴露。 |
| **规则 05（多余影子）** | 脚边多出第二道影子；出于外勤警觉，他猛地停步准备回头查看身后是谁（*“谁在后面？”*）。 | 第一时间喝止“别回头，保持步速往前走到壁灯下”；未拦截则回头直视高维实体截面触发认知过载/失联。 |
| **规则 07（自开的门）** | 发现刚才亲手关紧的门已悄然敞开；以为没闩牢或走近路，径直准备穿门而过（*“刚才没关紧？走这边近。”*）。 | 叫停并坚持改道绕行；未拦截则撞入高维尾迹或空间错位陷阱。 |
| **规则 08（挂钟同停）** | **核心机制碰撞**：因霍铎守着 **H6（整点前撤离）** 而有极强的看表习惯，在连续两间挂钟同停的房间里，他会习惯性伸手掏怀表看离整点还有多久（*“我看看表，离整点还有几分钟……”*）。 | 立刻打断他掏表并拉他退回值班室等整点；未拦截则其个人时间基准被同停区锁死。 |

**排查 AI 交互原则**：
1. 霍铎自主领路与排查，按 H1–H6 独立执行动作，无需玩家逐帧遥控；
2. 每次踩中 04/05/07/08 盲区前必给足 **3–5 秒明确动作前摇与语音/字幕提示**，确保判定公平；
3. 玩家通过喊停、提醒或抢先行动即可干预，成功救援会提升信任度，失败则触发真实规则后果。

## 五、开局场景与第一章重构逻辑（废除“换供能核心”）

- **开局时间与人数**：**黎明前的深夜（约凌晨 03:30–04:30）**，公共大厅内**仅主角与霍铎两人**（其余在册学员不在大厅）。
- **苏醒顺序**：霍铎早醒约 **1–2 小时**（外显记忆封存，但身体保留 H1–H6 内隐外勤习惯）；**主角自然醒**（非被霍铎摇醒），起身走向大厅中央时，第一眼撞见霍铎正低头对表紧盯傅科摆中心点（无声演示 **H1**）。
- **出门动机（零全知 NPC、纯物理排除法）**：
  1. 大厅是两人唯一的安全区与枢纽；傅科摆周期不再是 7.0 秒（开局异常为 8.1 秒）且绕开中心，说明**大厅本身正在滑向空间异常区**——若坐以待毙，整点钟声一响（**H6**）连大厅也会被卷入重排，四周门道错位（规则 03/07），彻底断绝退路。
  2. 大厅内部毫无外力损坏（符合**规则 02**），唯独**北翼门缝正往大厅渗贴地白雾并夹带湿咸海盐味**。
  3. 霍铎并**不预知**“去北翼就一定能修好大厅”，只是基于排除法与 **H5 直觉**提议趁整点前进入北翼核查：排查门闸/漂流物、落闸隔离渗漏口并带回观测记录簿，先保住大厅撑过整点，再寻找其余同窗与离岛线索。

## 七、代管者底层行为准则补充

- **无恶意原则**：代管者本身没有伤害学员的恶意，并严格遵守《十二条对赌契约》第 7 条（不得伤害学员、不得令学员在无知状态下丧命）。
- **高维实体化危险**：凡人遭遇的“不可直视”灾难（如规则 05 多余影子回头、规则 07 撞进刚穿过门的尾迹），源于高维实体在三维空间实体化本身的认知过载（`[数据删除]` 级后果），而非代管者的恶意猎杀。
- **低维安全外壳**：代管者平时呈现的“衣冠整洁、礼貌克制的旧式管家”形象，是其为了不伤及学员理智而主动维持的低维降维外壳。
