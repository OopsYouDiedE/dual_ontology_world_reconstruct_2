# No Morning Follows ·《沉睡学院》主旋律

> 最新试奏：[《同一夜》四版试听、总谱与评估](../../Music/theme-studies/README.md)。下文保留早期稿《No Morning Follows》的记录。

这是全作的旋律样带：夜班守则和学院的神圣秩序先被听成一种保护；同一句祷告在晨钟之后又被唱起，秩序变成无法摆脱的时间。公共大厅、队伍与观测台仍各有局内作用；整部作品的脉搏来自从发册到再发册的回环。叙事依据见[夜班交接](night-watch.md)。

录音中的时间为发行版本的近似定位。混音对照基于公开音轨的试听材料和信号分析（分窗总体及低频电平），由谱面确定声部与演奏写法；单凭电平不辨认乐器。样带中没有采样参考曲，所有音符和音色均由本项目生成。

## 给演奏者与混音的四个落点

| 小节／首次出现 | 写法 | 玩家听到的含义 |
| --- | --- | --- |
| 1–4 · 0:00 | E–G–F♯–C 是核心。F♯保持附点时值，跳到短促的 C，再停住 B。管风琴压在 E 上；上下声部逐个进来。第 4 小节以 D♯和一口气挂住。 | 远处有人照例发声，学院已经在运行。唱法收拢、气息均匀，接近低声诵念。 |
| 5–12 · 0:14 | 同一抬头仍出现，内声部转进 F 自然音；钢琴从间歇单音变为规则分解。第 12 小节短一拍，男低和男高仍在原地拖住 E。 | 上方在走，底下的时钟没动。句尾原本预计还有一拍，学院提前给了下一句。 |
| 13–18 · 0:41 | 女高升到 E5，男高和女低同向托高，随后音堆中分出半音与逆向运动；元音从 oo 打开到 ah，仍按原拍。大提琴保持有弓压的长线。第 17 小节第一次钟击。 | 神圣力量在此显形。高潮的分量来自音域与人声共振，钟只做一次仪式动作。 |
| 19–24 → 1 · 1:03 → 1:23 | 第 19–20 小节女高音原样重唱开头，女低却改唱 C→D→E；末段 E、F 与长悬留 C 形成挤压。第二次钟击落在最后一个短小节末拍，钟尾和管风琴跨过零点，女高音在原位置再次起声。 | 第一遍开场像召请；听过一次钟后，同样的开场变成重置。回环保留余响，让玩家认出已经走过这一夜。 |

人声样带是可重复生成的音素与合成共鸣，用于核对入口、重音和强弱。真人录制首轮读谱时，先以无伴奏四声部试唱：第 1 小节听清独唱与男高的先后；第 19 小节检查 C 是否听得见而仍让女高在前；最后四小节一口气唱进下一轮。正式实机是否使用完整混音，等听审确定。本提交只交付主题曲总谱与双循环试听，不改变局内 SFX 或出征流程。

## 复现

从仓库根目录运行：

```powershell
python tools/music/main_theme.py              # Python 3.10+，校验并导出 MusicXML
python tools/music/main_theme.py --render     # NumPy、SciPy、FFmpeg；生成双循环 MP3
# 用 MuseScore Studio 或支持 MusicXML 的制谱软件打开 XML，可再导出 PDF。
```

生成器校验每声部小节总时值、跨小节延音及人声音域，并检查循环接合处 PCM 跳变量。试听前一秒淡入，之后完整跨过两道乐句边界；结尾截在第三次开场，用外加淡出收束。
