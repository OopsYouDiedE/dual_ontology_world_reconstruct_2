## 交付分级

| 等级 | 证据 |
|---|---|
| 机关原型 | 原理、正反用例、MCP 操作、实机连续状态截图。可保留成熟部件。 |
| 待攻题 | 冻结源码哈希、路径与命令合同、黄金解已通过实机，向红队隐藏黄金解资料。白盒红队可读冻结的规则/地图/输入接线。 |
| 淘汰 | 任何独立红队凭合法输入从初始状态解决，包括自己发现的设计内解。用实机输入或同一权威裁判复现，记录时间和输入。 |
| 待 Astra 判定 | 20 小时已满且期间没有通过复现的破解；保存带哈希的黄金解、两名 Medium 与一名独立 High 完整轮次回执、主线渲染回执和审查拼图。缺记录保留待定。 |
| 已验收 | Astra 单次只读定版包；解法和画面均通过。Astra 只读文件，不运行游戏、补抓截图、做调研或写修补。 |

公开冻结源码可以独立推导合法通关；白盒测试不读取官方黄金解，不写状态、不改脚本、不访问同轮尝试的工作区。合法通关成立后无需把同轮时间耗尽。地图、拓扑、规则、输入或可见线索变化后，以新提交重新冻结；单独做实机复核时要标出参与测试的版本。

执行 `python tools/mechanism_trials/gate.py <ledger.json>`。gate 以带时区的冻结时间、同提交报告和实际文件 SHA-256 为输入；只有到点、有真实轮次回执、证据齐全才能进入 `eligible-for-astra`。测试：`python -m unittest discover -s tools/mechanism_trials -v`。

## 定版包给 Astra 看的顺序

1. `brief.md`：一页房间目标、控制、可见提示、四类耦合和逐步因果；列出是否有伤亡、硬失败、重试和所有 ≥40 ticks 提示的起止。
2. `contact.jpg`：统一等轴机位的正/反例与黄金解，额外角度用独立拼图；附原尺寸 PNG、帧清单、渲染回执和逐步状态。
3. `golden.json`、`live-trace.json`：可读动作序列、最关键的状态断言，以及最终结果；源码哈希表定位每项断言。
4. `gate.json`：本题冻结/到期证明、独立红队方法与回执。Astra 只需读包后逐项勾选因果、公平和美术，任一项否决即可退回。
