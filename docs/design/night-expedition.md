# 夜行学院 · 重构说明

## 操作

- 正式入口仍是 `scenes/rogue/Run.tscn`。开局自动翻开规则卡：按 **Tab** 或点击按钮收起，随时可再看。
- **WASD** 移动；点击场景捕获鼠标，**Esc** 释放；也可用 **Q / R** 转身。靠近对象或门后按 **E**。底部按钮同样可调查或穿门，但时间雨必须实际站到选中的地面标记。
- 到公共大厅后，在 **Crew & facilities** 选出征成员、安排治疗、用补给升级设施；**Sliding wing** 可以推房间。板块上的 `N/E/S/W` 是门口朝向，只有两扇门相对才连通。拼图不挡常规路线。

## 实现

| 系统 | 实现与设计取舍 |
| --- | --- |
| 入口与地图 | 保留原来的种子约束房间图、原生建筑蓝图和热厨；前段从入口到营地至少经过 10 个房间（含入口、不含营地），路径上必遇三处规则事件。前段必遇 1–2 名可主动邀请的幸存者；不邀请可独自抵达大厅。大厅补招未入队者但不自动部署，共有四名可招募 NPC，玩家之外最多带三人。 |
| 规则怪谈 | 回声走廊用真实钟面与倒影，走错方向会受伤；正确折返会在同一走廊重新定位。时间雨在红线上加速时钟、降低精神力；黄铜线的尽头须等灯稳定。馆长的红字规则仅在证据支持时能抢到物资，否则致死；等待旧规则的钟声总能过关。 |
| 死亡继承 | 死亡后可自由填写告诫（默认提供与死因有关的建议），增加一条、改写最后一条或擦掉最后一条，三选一。编辑的是可继承的手写边注，不是四条保底印刷规则。本地存档 `user://night_field_card_v1.json`。 |
| 同伴与家园 | 沿用营地活动模拟；同伴在场上沿队长的足迹跟随。专业匹配可提示或处理线索，压力和信任影响是否听令。多人时普通房间要求确认信号后单列通过；同一个正确的信号若配上跟随殿后者幻影的队形，也会触发代价。受伤自动撤回大厅；医务室加速疗伤，守夜灯改善恢复。出卖可强过一个障碍，但会导致伤病、信任损失和目击者压力。 |
| 滑块拼图 | 固定大厅和观测台，中间 3×3 布局可滑动；真正改变门边，用现有房间蓝图渲染。只能在安全区编辑，避免出征队伍被困在图上。 |
| 渲染与声音 | 第一人称眼高相机；复用建筑实验中的实体悬灯，用局部色温、逆流雨幕、低精神力倒影及连续机械低鸣营造差异。外窗继续使用独立的时钟光照信号。 |

## 开发检查

使用 **Godot 4.7.2 .NET** 与 **.NET 8**。下例的 `godot` 指本机的 Godot Mono 可执行文件。

```sh
dotnet build DualOntologyWorldReconstruct2.csproj
godot --path . --editor --import
godot --path . -- --run-seed=1
dotnet run --project core/rogue_topology/tests/DuelView.RogueTopology.Tests.csproj
godot --headless --path . -s res://tools/test/house_map_bridge_unit.gd
godot --headless --path . -s res://tools/test/night_expedition.gd -- --no-rule-save
```

无头场景测试覆盖十二个种子、实际雨道触发、红字安全与死亡分支、遗言继承、拼图与真实门连通、出卖后的疗伤/信任，以及抵达观测台通关。`--no-rule-save` 隔离规则卡保存。需要硬件 Forward+ 进一步验收画面与性能；逻辑测试不替代实机渲染测试。
