# 《沉睡学院》· 夜班交接

> 历史章节与装置资料。当前制作入口见 [出征工作流](../handoff/expedition/README.md)。

玩家接到一份夜班手册，穿过六处封锁抵达公共大厅，再带着队伍把本局的名字送进观测台晨钟。英文是实机文本。以下涉及解法和主持逻辑，建议先试玩。

## 正式流程

- **WASD** 行走；点场景控制视线，**Q / R** 也能转身；**E** 查看或操作最近的实体，**Esc** 放下文件或释放鼠标。取到手册之后按 **Tab** 对照自己和队员的版本。局内的操作菜单必须从对应道具打开；门未释放时，门扇和碰撞均保持关闭。
- 第一位同伴必定在退信室获救，带钴蓝版。部分种子会在排水档案室接到一位赭黄版同伴。公共大厅抵达深度固定，分支宽度、连接、局部证据方向和入队人物按种子变化。拓扑约束解出每扇门；同层分支使用不同的原有建筑平面。
- 所有 17 份原始 `model_01`–`model_17` 仍是独立资产，从仓库提交 `a021fc2` 恢复。侦探是玩家，也是暗房出现的留影；其余 16 人是可交谈、招募的大厅居民。战前出征队最多三名同伴。大厅居民沿现有建筑行走，按自己的需求选用家具。

## 守则与现场

| 版本 | 管路冲突 | 随身文件冲突 |
| --- | --- | --- |
| 象牙 Ivory | 收声，等公共线静下来；保持彼此看得见 | 将文件贴身穿过干区 |
| 钴蓝 Cobalt | 在仍保留呼叫时回答一次，留在话亭等回执 | 先把文件放进传递柜再通过 |
| 赭黄 Ochre | 不占用公共语音线；在独立转接盘留下回执 | 把湿文件摊在托盘里，干后自己带走 |

每一册都把某类领路人的成功经验写成随身程序。读到的是动作、处境和撤退建议；手册不显示模拟变量、阈值或异常来源。现场呈现的是干灰与湿痕、重叠签章、倒序回铃、错配底片，以及真实设备动作。危险由局部驱动、湿负载、残留回响和机械负载组合产生。同一句规程在不同设备状态下可能需要先做准备；例如刹住吊笼和打开旁路可以独立避险，望见双印后还需先给门闩卸力。

队伍在处理分歧时为每个人分配「工位 × 时段」：同一工位同时接到不相容操作时交接无法成立。两个话亭并用，或轮流用一个转接盘，是两种不同的排程，游戏逐轮显示谁在做什么，随行队员移动到工作位置。单版同行时玩家可以临时按队友的方式做，队友仍保留原册。开场尝试让队员改用象牙版会被拒绝。大厅以后的派发处才接受共识：要么出示两份独立签字证词与两条现场记录，要么此前至少有四次把握明确的行动，并且每名队员的信任至少为 3、压力低于 3；仍可继续分线。

## 全部房间、线索及打法

| 房间 | 看什么、做什么 | 可行路线与回报 |
| --- | --- | --- |
| **Night Dispatch** | 递件柜的发放闸、卷盘和夹封手册；退件册的象牙色装订线。 | 从正常发放闸或印刷夹领册；也可回卷取出退件副本。两者都开启手册与第一道门。 |
| **Undeliverable Office** | 日期不同的 REED / ASH 铜眼纸牌；对照记录上取掉卡扣的一栏。 | 按记录投递正确牌，额外留下一箱补给；或把退信绳系到固环，再用检修钥匙。救出的同伴带钴蓝册。 |
| **Blind Switchboard** | 现场命令要求同时回应；维护簿上失败签字共用线路，两个话亭接口彼此独立。 | 放下隔断，各逐本处理；或堵住共用话口，再沿着绞盘一人一轮。队友均为同一版本时，玩家可按其程序过一回。照告示齐声回答会造成损伤。 |
| **Pump Archive** | 铜弯管两只接头干湿不同，收件页上只有一条完好印记。 | 放掉底部压力，往干灰未动的一侧排水并取补给；或把文件装进蜡套，等过喷溅后走滴盘下。部分种子在这里接到赭黄册持有人。 |
| **Counterweight House** | 空笼的吊点偏离一侧；不同种子的日志告诉玩家哪一端过重。 | 先落棘爪，再把配重拨向相反方向；或者刹停卷筒、拨开下方滑道的逃生扣。碰运气拨配重会挨到失控吊笼。 |
| **Dry Ward** | 大告示要求把所有纸放进一个柜、同时进入；旧记录却有两张独立干脚印和一张墨团。 | 展开干凳和晾盘，分人分工作台；或用运输销卡住内锁，一人完成后再复位。不同版的队友会拒绝共用投递槽。 |
| **Curator’s Barrier** | 红字要求抢在铃前过闸；固定盘的铃标、双印和闩下检修鞋各给一条线索。 | 消掉一个回铃后按手册等铃；卸力后用检修鞋过旁路；双印完整并卸力时可抢先捡到两箱。押错红字伤三点生命，仍可补救。 |
| **Public Hall** | 安全营地、独立目击者、交接鸽巢和双线勘察卷。 | 记录两份有名证词后在归档柜报到；或直接拓录签过的勘察卷。可用补给升级瞭望灯、诊疗室或安排换班。 |
| **Fixing Room** | 底片匣两面和试印条，铜背和黑釉只得一面成像清楚。 | 把冲洗液降到铅笔线，定影对应一面；或者盖好片匣回卷，绕过开放冲洗槽做干式接触印。冲洗错误会见到人脸、名字错位的留影。 |
| **Dispatch Exchange** | 两套各自可读的装订回执，及一个重复签名的公共喇叭。 | 断开两组绕线，按实际到达顺序合订各自回执；或者凭证据或高信任签成共同守则，再关闭公共回响发出一份。 |
| **Observatory** | 空白回铃栏、载有全队名字的纸卷，以及铭着双手记号的手摇轮。 | 切断返程再署名拨钟；或封纸卷、卸传动，带着名单手摇一整圈。鸣钟结算，本局名册成稿。 |

失误消耗血量、加重随行者压力并保持门封闭。大厅补给可建设设施，出征中受伤的后卫撤到诊疗室。死亡可留下至多一条 180 字符的边注给下一轮；同种子复盘保留门图和现场证据。

## 资源与验证

- `scenes/rogue_crossing/`：成套场景文本、隐藏状态、队伍排程、角色复用、实体动作与正式入口流程。
- `assets/architecture/night_crossing/`：11 台成品家具及连通门的 GLB。黄铜倒角、叠层纸、管道内外壁、螺钉、连杆等均在 Blender 模型中做成；实际工作零件使用独立枢轴。Godot 另挂局部印刷文字、光、声和碰撞。`tools/night_crossing/model_fixtures.py` 保留源模型生成流程。
- 拓扑由 `HouseMap.generate_watch` 接到项目原有约束求解器；`HouseMap.generate` 留给旧实验回归。原建筑实验入口 `--architecture-lab` 保留。旧战役的晚祷簿与滑翼依然有各自的实验和回归脚本，正式夜班主线由上表覆盖。
- `tools/test/night_watch.gd` 验证两种证据、多个解、冲突、共同守则与整局状态；`tools/night_crossing/viewport_run.py` 向项目 MCP 发实际 WASD、E 和鼠标点击，把整条线路从发册打到晨钟。
