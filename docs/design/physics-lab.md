# V2 十机制实验场

独立场景 `res://scenes/physics_lab/Lab.tscn`，按用户提供的 `v2.html` 的 L1–L10 顺序排列。各展台的轴测模式对应参考图的剖开房间，眼高模式用于检查门框、路径和机关遮挡；L03 已换成可步行的第一人称关卡。浅灰白石材、冷暖浅染的零件、石墨导轨、刻线和明暗传达状态；光学采用低饱和的细光路。战役入口及工作区内的 R2／R5／R7 原型保持原样。

## 打开与取证

```powershell
$lab = '.runtime/godot/4.7.2/Godot_v4.7.2-stable_mono_win64_console.exe'
& $lab --path . --rendering-method forward_plus --resolution 1280x720 res://scenes/physics_lab/Lab.tscn
& $lab --headless --path . -s res://tools/physics_lab/verify.gd
& .runtime/python/Scripts/python.exe tools/physics_lab/capture.py --out .runtime/physics-lab/final
```

`[` / `]` 选房。展台中，`1–4` 操作当前展台（也可按屏幕按钮），`Tab` 切换机位，`R` 重置实验，`Space` 暂停，暂停时 `N` 精确推进 20 个物理步。每个房间有对照条件和成功条件，可以自由重试。眼高模式是固定观察位，L4 随门洞选择换位。

`Model.gd` 按 60 Hz 推进，`Geometry.gd` 只呈现同一份装置状态。`capture.py` 用项目 Game MCP 的 InputMap 和真实 Forward+ 视口驱动同一场景。`manifest.json` 将每张 PNG 与房号、机位、物理步和状态绑定；`trace.json` 记录每次命令后的状态哈希，便于两次独立运行逐步比较。复现时，开场先暂停再重置，排除加载耗时。

## 逐关对照（归档展台）

| 实验 plate | 对照 → 成功条件 | 在模型中验证的量 |
|---|---|---|
| 01 三片偏振门 | 0°／90° 交叉为暗；中片 90° 仍暗；45° 或 135° 恢复透射，探测器解锁低门洞。 | 理想线偏振器，入射非偏振，`I/I₀ = ½ cos²θ sin²θ`；45° 时 12.5%，门槛取 10%。 |
| 02 驻波回廊 | 对照廊与可移反射墙并列；原节点变成高振幅位，触发 40 步前兆；换到新节点站满 60 步。 | `λ=4 m`；墙平移 1 m（`λ/4`）交换节点和波腹。提案的 `λ/2` 保持振幅节点原位，已在头测加对照。 |
| 03 凝视气闸 | 望向桥但熄灯，或灯亮而移开视线，都无锁定；恢复照明和射线命中，协作过桥。 | 实验视点的 27 根射线与桥舱实体范围相交；远端联动闸读取反相位。失去视线暂停过桥，40 步中止，可在窗内恢复。凝视锁定与反相闸是虚构联锁。 |
| 04 折叠拱廊 | 首三次右转仍在一层，第四次到二层同号门；反向可回。 | 双层四扇门拼接图；探针穿孔后转 90°，查询目标段的几何命中：近侧 `6 m`，上层 `12 m`。展台用门洞离散切换观察位。 |
| 05 双室分选 | 常开也放行慢球；按测得的速度位只放快球入右室。 | 取 2/4 m/s、等质量粒子代理。两侧各两颗时，总能量计 2:8；一位锁存器已占用时必须清空，清空计数单列。门使用能差阈值代理，热浴和热回馈留给后续。 |
| 06 倒刺竖井 | 逆向行程过阈值后可制动；反转局部重力，分两趟把两块配重送上层；侧袋同样可达。 | 分离有符号重力和世界高度；逆重力累计行程阈值 0.45 m，40 步中止。出口要求两件配重分别交付。 |
| 07 炼金渡口 | 原料直接入水遭拒；磁化 → 浮升 → 发光，依次解除三锁，降桥接通两岸。 | 四态确定性转化图，上一段需到站；石墨门闩的位置、料坯位置和桥的升降与状态机一致。 |
| 08 磁通交错厅 | 同样抛射在相反磁场下走镜像弧；静止磁体无 EMF；移动穿线圈时工作门被打开。 | 匀强场垂直入射解析积分；线圈取归一磁通剖面 `Φ(z)=exp(-z²/0.72)`，`EMF=-ΔΦ·60`。阈值触发 60 步保持器；运行中换极前兆 40 步。 |
| 09 光行时差与回声 | 两侧实测信号到达顺序相反；切换参考系后看校正的事件时差；堵住回声触发告警，换站可重播并双压板。 | `c′=3 m/s`，事件差 20 步、间距 4 m；移动参考系 `v=1.8 m/s`，`Δt′=−0.583 s`，固有钟速率及尺缩均为 0.8。记录 60 步的离散站位，回声因果阻塞后回滚并保留记录。 |
| 10 纸带前厅 | `1000` 拒绝，`1100` 接受；逐步观察读写框抹零并前进。 | 四格可写数据和一格终止标，`Q0/Q1` 跟踪奇偶，60 步读写一次，终止格停机。头测穷举 16 种输入。 |

物理查对线索：OpenStax *University Physics* 的偏振、驻波、电磁感应与狭义相对论章节；MIT Game Lab 的 *A Slower Speed of Light* 用于参考放大传播时差的表现。L3/L6/L7 的异常联锁作为提案的玩法假设测试，L5 的能差与寄存器是可重复的控制实验。

## L03：凝视接力

正式浏览的 L03 是独立的第一人称关卡。`WASD` 步行，鼠标或方向键转头，`Ctrl` 下蹲，`E` 近距离面对面交谈，`R` 重开，`[` / `]` 返回展厅横向浏览。旧的 L03 展台由 `-- --lab-archive-observer` 保留。其余九个展台和正式战役保持原样。

- **直接观察桥本体。** 入口视野正前方是第一段断桥。观察者眼高的 27 射线，必须首碰桥自身受聚光灯照亮的有效面。A 的有效面在上方，B 的有效面是桥构件外伸的侧肋。声响和实际桥面标记凝固、失视和释放。失视 60 物理步后桥面与碰撞一起消失；安全网只送回走到过的实地。光学段使用实景光源的锥角、范围和遮挡查询；观察维持实体是虚构规则。
- **让 Hale 亲眼见到反例。** 他相信直视悬桥的人会被光夺走。你走进光、踩到桥面，再安全退回。只有 Hale 沿真实视线观察到了这段行动，近身对话才允许修订这条禁令。关卡没有通讯报告、试重、灯开关和远程发动按钮。
- **两次交换观察者。** 你看住 A，让 Hale 先到中岛。从这里他能看见近岸不可能看到的 B 侧肋；你走过 A，蹲过实体矮梁，再通过 B。走 B 的人看不到自己的脚下那条外伸侧肋；到远岸标出的侧位后你才能接过观察，再让 Hale 通过。两人到齐，出口开门。窗、墙、矮梁和桥都可在真实视角检查；危险动作在暗井里可恢复。
- **R-05 的正式西装。** `assets/characters/mpfb/r05_formal.glb` 来自在「测试 MPFB2」试装场生成的同一份 `r05_suit.glb`（MakeHuman CC0 `male_elegantsuit01` 与 `shoes04`，使用项目 R-05 体型、贴合蒙皮及骨架）。复用原审阅场的柔色阶 Toon 与反壳描边，同时保留服装底色贴图。冷、暖定向聚光分别负责路径和人物读形；角色保留程序走姿、原生屈膝取样与头部视角反馈。

`Walkthrough.gd` 只发送与手玩等价的步行、镜头、蹲伏和交谈输入。录制从进门时的空桥开始，以双人到达和 `AIRLOCK CLEARED` 收尾，保留游戏音效。回归包含暗灯和转身失视、多个近岸位置的 B 遮挡、B 行走面无法自持、两侧观察位、矮梁碰撞、未观察到的反例被拒、两段实体碰撞与坠落回原岸。新设计的可发现性仍待首次游玩的人无提示测试。

## 归档展台的验收边界

头测 10 组全通过，Forward+ 两次均完成 49 张实机场景取证，243 条状态哈希逐条一致。一次只读 Astra 视觉审查后，加了桥头格状倒计时、上下层门槛配对刻纹、回声轮廓与纸带顶面读数，再重新取证。

归档中的十种机制作为可操作展台单独验收。战役集成还需接入战役的遍历碰撞、伴随 AI、手册证据与说服、跨关种子预算及留出评测。尤其 L4 的双层坐标拼接已经可测；连续行走穿门和实时递归门内视图属于战役集成阶段。

现有战役的回归另行执行：43 项中 5 个失败、3 个错误，集中在旧 R5 的证据／策略路径及 R7 预警采样。战役的 Witness／Target／Sol 成绩不计入本实验结果。
