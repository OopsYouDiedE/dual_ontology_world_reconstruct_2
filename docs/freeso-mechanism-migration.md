# FreeSO 机制迁移与验收清单

以[选型固定的 FreeSO 源码版本](building-topology.md#生成器参考选型)为主参考，在 Godot 和 C# 的现有正式入口里逐项接入。每项保留原有剧情事实、存档格式与资源 ID；先用真实场景副本复现，再在冻结版本上满足适用的验收项后切换对应机制。本表的「定点」指开发证据，「待实现」指尚未接入；正式分段评审仍按项目评估与评审流程执行。固定提交的全仓路径盘点与源码入口见 [FreeSO 源码索引](freeso-source-index.md)。

| 机制 | 接入进度 | 验收用例 |
| --- | --- | --- |
| 建造试算、提交、撤销与重做 | 已接入建筑编辑器；墙、地板、栏杆、门窗、生成布局、移动、复制、删除、参数编辑和导入共用候选提交。独立地块服务的建筑权限及命令验证待接入。 | `B-P` 隔墙、加门、撤销；过期草案、跨文档草案和重复提交需拒绝。保存、导出与撤销状态逐项比对。 |
| 房间划分、室内外、支持面与生成 | 单层闭环、走廊、门洞与承载栅格已接入；基于房间用途和相邻约束的布局、地块边界、室外地面、跨层承载、屋顶待实现。 | 48 个种子例；断墙、拆隔断、室外有地／无地、楼面挑空。随机生成后验证房间用途与路线，检查旧预设可加载。 |
| 家具与构件 | 手工新增、自动布置、按房间清空、移动、旋转、复制和单件删除走候选事务；任意多选批量编辑、物件表面支撑与容器待补。 | `B-P` 取消后数据完全一致、清除与新增家具可一步撤销；检查双视口、出入口、站位和原证物可见性。 |
| 楼梯、楼层与路径 | 楼梯几何走候选预览；建筑器开启的多层生活局已用楼梯落点及逐层栅格寻路，核心动作目标和存档保存高度；复杂装饰件阻挡和完整实机走楼梯待验收。 | `F01` 实际预设：下层→平台→上层及原路返回；移除楼梯、封堵落点或改变楼梯方位后重算路线，不穿楼板、不走出栏杆。 |
| 门状态、路径与占位 | 门洞与家具碰撞、正式生活模拟单／双扇门开关和全局上锁已接入。门槛有人时拒绝关闭，门状态变化后刷新路线和动作可达性。社交及物件动作接近点在执行期间预留，后到角色避开已用或已预留的位置。通行权限、通行排队及路径中段动态避让待接入。 | `B-P` 开门／封路；双角色对向过门、关门后二次寻路、离开释放占位。 |
| 角色效用、需求和环境 | 正式生活模拟已使用实际路程过滤、排序物件动作；需求衰减、需求状态与房间环境作用仍按现有实现，待逐项迁移验收。 | 固定 `B-P` 初始条件对比直通、绕路、封死与不口渴；再跑一日模拟、动作中/动作后变化和恢复存档。 |
| 行为执行、交互与队列 | 待对照 FreeSO 的交互条件、行为调用栈、动作队列、打断与效果声明，接入现有角色行为入口。 | 目标消失、前提失效、打断和恢复；行动效果至多一次，连续动作按优先级，剧情固定演出保持原时间线。 |
| 社交、关系与角色状态 | 接近阶段已按 FreeSO `VMSlotParser` 的邻近候选、可站立筛选和朝向规则重做：同层视线、距离、已占位置和实际路程决定站位；目标移开时在到达前重算。关系数据、双方同意、行为及持久化仍待逐项对照。 | 在真实聚集场景验证双方可达、拒绝、多人竞争、重复行为、关系锁和读档。 |
| 物品、经济与在线地块 | 待盘点物品转移、所有权、资金及权限、地块访问、联机同步/会话；逐项映射为项目规则并设计存档迁移。 | 转移守恒、权限拒绝、回滚、重连后无重复操作，验证剧情资源 ID 与旧档不变。 |
| 其他 FreeSO 模块 | 待完成源码级全量盘点，包括建造与对象工具、渲染/音频、资源格式及服务端玩法模块。 | 为每项登记对应入口、依赖、数据契约、测试与切换记录，单独追踪。 |
