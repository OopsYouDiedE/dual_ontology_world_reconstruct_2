# 四区开场与十六人的协作结构

核心玩法是**组队调查与现场指挥**。玩家最常做的判断是：眼前这条消息值得谁去核验，现场还要留下谁，以及小队用什么信号向下一班交差。怪谈给每次调查提供不同的条件；指令把这些条件变成角色要承担的工作。点名承担清点、找缺席者、给迟到者留饭的日常功能。

## 已接入五日主线的开场

侦探从乙区进入故事。玩家先亲手调查一扇门，再通过同一根管子接触另外三种处境。四翼听到的都有人可以作证；会面时要解决的是这些证词之间的矛盾。

| 时间 | 玩家在做什么 | 留给下一场的东西 |
| --- | --- | --- |
| 07:00–08:45 | 在 R05 醒来，去乙区小厨房。对照抓痕、拖痕、湿布和棘轮，复演门口的人各自做了什么。 | 苏泠记得有人喊开门；霍铎能解释反扣的机械结构。两人对危险的判断都有具体来处。 |
| 09:15 | 甲区通过管道报出勤务梯；沃德要图，雀儿保留原件。玩家让苏泠复听，或让霍铎敲管测试。 | 10:50 丙区来电时，由先前选的人用自己的办法核对。地图仍在甲区，玩家尚未见到手铐。 |

## 三十余日的扩展结构（设计提案）

建议把「团结」写成一项可观察的能力：**指挥者失联时，十六个人仍能把最后一班人接回来。** 第一天已经可以互救；长线的进度来自接下来陆续获得的委托权、替班能力和共同处置风险的经验。下面是建议的三十五日节奏，现有可玩剧情仍为五日。

| 阶段 | 学员面临的具体难题 | 玩家交付的成果 |
| --- | --- | --- |
| 1–5 日：敢于互证 | 一翼保存原件，另一翼握有反例；证人还要回去照顾伤员。 | 约定谁保管原件，谁带回可复核的副本。沿用现有五日的风窗、配给、投票、阀路与结案作为第一宗事件；长线版需另接后续事件。 |
| 6–12 日：第一次替班 | 原来的见证人要休息；替班者只听过转述。某扇风窗只在另一侧有人观察时才通向原走廊。 | 两名新人分别从两侧验证适用条件，并各自带一次班。旧搭档因此有时间接另一宗调查。 |
| 13–21 日：两地同时出事 | 北侧异常要保持观察，南侧配给仍要继续；全员赶去同一处会丢掉一个现场。 | 玩家给两队分别下目标、撤回条件和回报时刻。某队迟到时，留守者凭上次亲自验证的条件决定派谁接应。 |
| 22–29 日：授权他人改令 | 现场见到的出口与出发时不同，原指令会把伤员送去错误一侧。 | 小队长有权改道，并在事后说明证据；由承担绕行代价的人修订下一班交接单。玩家开始能把一整条路线交给别人。 |
| 30–35 日：整校接力 | 同一条撤离路线要有人在入口识别条件、途中留守、出口清点、后方接替。指挥者自己也必须经过这条路。 | 玩家排出含替补与撤退条件的四班；最后一班在玩家已经离场后独立完成交接。迟归者得到接应，就是团结成立的演出。 |

日数作为编剧预算。实际进入下一阶段的条件是上一阶段留下的成果能否被另一队使用。排班界面建议只让玩家填写四件事：**谁带队、查什么、遇到什么撤回、向谁回报**。角色拒绝命令时给出眼前理由，例如「我走了谁扶他下楼？」玩家可以换人、派替补，或者先承担照护工作。每次返工都改变下次可用的人手或信息，每次成功都减少玩家需要亲自盯住的一件事。

编写每一宗怪谈时，先答三问：哪一项异常必须在这个时间和地点才能看见？谁能从另一侧独立证实？若玩家判断有误，哪一班人将承担怎样的后果？危险规则提前给出安全路线；联络和借用程序允许补救；重大关系伤害留给玩家能理解利害的公开决定。这样，同一座学园可以反复承载不同规则，玩家也能认出这些人是怎样学会一起做事的。
