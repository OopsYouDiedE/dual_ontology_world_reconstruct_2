# Expedition-01 深度扩展与 AI 闭环 + 暴力边缘解算设计方案

本方案严格对齐 [沉睡学院｜箱庭关卡设计指南](level-atlas/index.html)（第 3–5 页拓扑构件、状态空间穷举与跨层交叠案例）及 [单房与楼层布局规范](layout.md)，用于将首通破解时长从 **8–10 分钟** 拉升至 **18–25 分钟**，并彻底消除“单人潜行主桥 + 拔芯狂奔”的无脑支配策略。

## 1. 延长破解时间与扩展候选动线的四大结构升级

1. **新增 2 个必经联锁房间（拉长核心主链并制造“先见门→绕路解→回程用”）**：
   - **B6 稳压阀室（Counterweight Valve Room）**：紧邻 B5 总控室与 B3 试验区。B5 黄铜总闸不再一键拉开，必须先在 B6 完成配重稳压（或从 B3 侧道切入），同时 B6 预留通往 C2 桥下环道的单向检修门（`The Witness` 机关与被改变空间相邻原则）。
   - **C3 蓄光配电室（Photometric Relay Chamber）**：位于源井对岸。源核锁在稳压罩内，需先绕入 C3 合闸蓄光（同时可打开返回 B4 信号夹层的上层检修回环），避免“过桥即拔芯即跑”的短促节奏。
2. **确立 4 条真正互斥的井区候选动线（消除单一最优解）**：
   - **动线 A（双人协同·北窗主桥）**：带 Hale 进井，按 `Q` 直接派他上北窗盯桥，自己按 `R` 熄灯守**独灯律**快速过桥。
   - **动线 B（资源换安全·南侧窄栈桥）**：甩掉 Hale 独行，免凝视考验，但高耗灯油（逼迫提前在 A2 侧龛 / B4 暗廊 / 检修回环搜油）。
   - **动线 C（工具强冲·节拍器诱饵主桥）**：解开 B4 信号夹层取节拍器，投饵换 12 秒窗口强冲。
   - **动线 D（低层潜行·C2 桥下环道）**：新增下层环形检修道，无凝视审判，全程静步听声定位并消耗中等灯油，并可直连 B6 阀室回环。
3. **加强 3 条跨层拓扑回返（`Caverns of Thracia` / `Undead Burg` 跨层复用）**：
   - `B6 稳压阀室 ↔ C2 桥下环道`（开闸后打通中后段双层回路）。
   - `C3 蓄光配电室 → B4 信号夹层`（对岸高处单向放梯回望中段，供缺油/缺诱饵玩家补给再战）。
   - `C5 撤离检修廊 → A2 静步侧龛`（撤离段新增第二条绕行支路，避免单一长跑）。
4. **反逃课机制与反应式台词**：
   - **全局灯油压力**（`base_oil_drain = 0.22/s`）、**真实独灯律**（独立累加 `0.55/s` 警戒，静步无法归零，Hale 直接喊出“按 R 熄灯”）、**单人主桥声呐脉冲**（无北窗或诱饵时每 4.8s 扫桥加警戒）、**狂暴猎手提速**（`3.8 → 5.4 m/s`）。

## 2. 双层自动化验证：AI 闭环迭代 + Bot 暴力解算边缘测试

- **AI 闭环实机优化 (`tools/expedition/ai_optimize_loop.py`)**：通过 `level_genome.json` 驱动真实 60Hz Godot 无头并发运行 **`CheeseBotTest.gd`（漏洞逃课机器人）** + **`WalkTest.gd`（合作通关）** + **`HearingTest.gd`（规则公平性）**，自动淘汰存在逃课漏洞的参数并收敛至最优基因组。
- **Bot 暴力解算边缘测试 (`tools/expedition/brute_force_edge_solver.py`)**：严格实现关卡设计手册第 4 页的**有限状态空间正向 BFS + 终局反向可达性标记**，在秒级内穷举所有 `(站位, 油量档, 节拍器, Hale状态, 闸门, 阀室, 配电, 源核)` 组合，数学证明 **0 软锁（Softlock = 0）** 并量化首通破解时长与反逃课边界。
