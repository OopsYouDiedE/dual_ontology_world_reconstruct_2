## 1. 手感（Movement Feel）

1. **三级速度 + 落地/起步曲线**：静步 1.55 / 走 3.8 / 快走 5.0 / 跑 6.4；起步 0.12 s 内插到 92%，急停按"是否同向"分 30/46 两档，空中操控降到 12%。
2. **脚步与位移强绑定**：步距改为 走 0.78 m、跑 1.05 m、静步 0.62 m，脚步音量/音高由 `speed_quiet`、毡垫、铁网表面三因素混合（现在只按速度三档）。
3. **落地反馈**：>3 m/s 垂直速度触发 `land_dip` + 一次 `kick`，并把 `stride` 归零，避免落地后立刻踩响一步。
4. **精瞄态**：按住右键（或手柄 LT）→ 灵敏度 ×0.45、FOV −6、准心环收紧；B3 凝视与投掷诱饵会在精瞄下给出可见的"视线收束"提示。
5. **阶梯与门槛**：把 0.19 m 硬抬升改成 `floor_snap_length` + 抬升前 `test_move` 双向校验（已存在，补一条"向下吸附"防止下台阶悬空 1 帧）。

## 2. 队友交互逻辑（Hale）

1. **指令环**：`Q` 打开 3 项意图（**跟紧 / 守位 / 去据点**），依据 `focus()` 当前可作用对象动态给项；鼠标或数字键选择，`Q` 再按取消。原先硬编码的"试闸/盯桥"并入"去据点"。
2. **队形与避让**：跟随从"踩点复制"改为 **侧后方 1.4 m 偏移 + 视线优先**；与玩家距离 <1.1 m 时向侧向让位（已有射线检测，扩展为"墙侧优先"）。
3. **主动报告**：Hale 每进入一个新音区（长廊／档案翼／井口／井底边缘）报一句；猎手状态变化、桥面视线计数变化时由 Hale 播报，取代玩家 HUD 的纯数字提示。
4. **信任值**：每次玩家指令被验证成功（如北窗守望真的锁住桥面、试闸真的没开）→ 信任 +1；信任高时 Hale 会主动提出建议并缩短犹豫时间（`north_pause` 从 0.55 s → 0.25 s）。
5. **可失败点收敛**：Hale 卡住（距离 >8 m 且 5 s 无位移）→ 自动传送回"最后一个玩家足迹 + 侧向偏移"，并播一句无损台词的抱怨。

## 3. UI

1. **左上面板重构**：目标（主）／当前规则契约（副）／资源（灯油 + 信任）三层；`prompt` 与 `notice` 合并为"准星下两行"，不会再互相覆盖。
2. **指令环 UI**：圆环 3 扇区 + 键盘 1/2/3 + 手柄方向，选中项显示一行解释与代价。
3. **规则卡**：进入新区域时右上角浮出"本区契约"卡（区域名 + 1 条规则 + 违反后果），2.5 s 后淡出；按 `Tab` 可回看。
4. **手册扩到 4 页**：01 原守则 / 02 实测批注 / 03 **契约 A** / 04 **契约 B**（新设计的两份规则怪谈）+ 操作页。
5. **失败卡**：`fail()` 后 3 秒展示"死因 + 违反了哪条规则 + 从哪个折返点重来"，而不是单行 toast。

## 4. 台词

- 重写 Hale 的 6 条关键台词，让它们**复述机制**而不是氛围：北窗、静步、诱饵、双人视线、撤离方向、召回。
- 玩家侧心声（无底板斜体）只保留"决策提示"，不再复述环境。
- 新增 4 条失败专属台词（对应 4 种死因），每局最多各 1 次。

## 5. 运镜

- 过门框/闸口：`fov` 脉动 −2、一次 0.18 s 的轻微俯仰。
- 凝视收束完成：0.35 s 的 `fov` −4 + trauma 0.12，配合琥珀色泛光。
- Hale 到位/回头：以 Hale 头部为目标的 0.5 s 视线辅助（不夺操控权，只给 ±6° 的软引导）。
- 撤离段：沿用 letterbox，但新增"警报 → 螺旋梯 → 检修廊"三段镜头重音（`punch(-3)` / `kick(.3)` / `fov +2`）。

## 6. 关卡物理结构

1. **铁闸**：升闸改为"先 0.15 s 抖动 → 升 4.0 m"，碰撞体跟随（`AnimatableBody3D` 语义），并在两端生成导轨摩擦声源。
2. **B3 板面**：保留 `collision_layer` 开关，但补"撤除碰撞时地面随之下降 0.55 m"的可见反馈（已有 `board.position.y`，补一条落灰粒子/音）。
3. **南栈桥**：灯油耗尽从"硬失败"改为"灯灭 + 强制折返（回头 4 m 内可救）"，超出则失败；给玩家一次纠错。
4. **螺旋梯**：`stair_wedge` 已有连续碰撞面，补"边缘护栏失效段"作为可选风险（可跳下省 40 s，但会惊动猎手）。
5. **门槛**：A→B、B→C 两处加可碰撞门槛（0.12 m），让脚步音效与地形一一对应。

## 7. 房间拓扑（扩展决策空间）

现在：`A → B1 → B2 → B3 → {B4 暗廊 | B5 亮廊} → 信号夹层(可选) → C 桥区 → {主桥 | 南栈桥} → 螺旋梯(东/西) → 南检修廊 → 主廊 → 锚定厅`
可用决策 ≈ 8~10 个，C 段之后为纯执行。

改后拓扑（新增 4 个连接、2 个房间、1 个捷径）：

```
A1 长廊 ─┬─ B1 前厅 ─ B2 观察窗 ─ B3 试验区 ─┬─ B4 暗廊（灯油）
         │                                   ├─ B5 亮廊 ── B5' 信号夹层
         └─ A2 侧龛（新增，可选：一次静步挑战换 20 灯油）
```

## 8. 两份规则怪谈（新设计，成对且互斥）

**契约 A《值班者条例 · 第三码》**
> 一、井区每处只容一人注视。
> 二、若你与同行者同时看到同一块琥珀板面，须由**先看见的人**先移开视线；后看见的人继续注视，直到板面停止泛红（约 2 秒）。
> 三、违反者：板面会在 3 秒后整块熄灭，井底听见一切声音。

**契约 B《锚定厅交接簿 · 手抄页》**
> 一、铁网上的每一步都会被井底听成一次呼唤。
> 二、被呼唤三次而不回应（不回以静步），井底的东西会记住你。
> 三、记住之后，只有"投出会响的东西"能换回一次清静；一次远征只换一次。

设计要点：
- A 与 B **互为约束**：A 要求两人协同时刻，"先看见的人先移开"是可被玩家事先约定的（Hale 会复述），违反会产生**可听见**的后果（整井静音 + 猎手立刻苏醒）。
- B 把"跑"的代价具体化为**三次计数**（HUD 上以三颗铁珠表示），第三次之后猎手进入 `rage`，与现有 `rage` 逻辑对接，不改猎手核心。
- 两份契约都写成**可执行条款**（谁、在何时、做什么、违反如何），在手册里成页，进入新区域时以规则卡形式重播一次。

## 2. 队友（Hale）

- `Q` = **指令环**（序号 1/2/3、滚轮或点击），选项按 `focus()` 动态过滤：试闸／盯北窗（或召回）／跟紧我／原地待命／听他的建议（信任 ≥2 解锁）。旧的三态被"去据点"统一。
- 环上每个选项都标出**代价**，用契约的语言写（"契约A：双人同视会过载""契约B：他的脚步也会被数进去"）。
- **跟紧 / 原地待命** 成为真正的两种站位；`hold` 时 Hale 会转头观察玩家。
- **卡住自愈**：跟随距离 >13 m 持续 6 s，自动回到 `trail[0]` 侧向 0.9 m，并说一句"这儿有点窄，我绕了一下"（本轮截图里能看到它把话收窄过一次以避免误触发）。
- **信任值 0~3**：`visit_*`、`contract_a`、`niche_quiet` 等事件各加 1；信任越高，Hale 接受北窗任务时的犹豫越短（0.55 s → 0.25 s），并在 ≥2 时开放"听他的建议"。
- **主动报告**：Hale 自己播报视线冲突、井底状态（investigate/hunt）、被记住、铁网计数；玩家 HUD 不再只报数字。

## 7. 两份规则怪谈（已实现，非文案）

**契约 A ·《值班者条例 · 第三码》**
1. 同一块板面，每次只容一人注视。
2. 两人同时看见时，后看见者继续注视，先看见者一秒内移开。
3. 两者都不移开，或后看见者先移开 → 板面三秒后整块熄灭，井底听见一切。

实现：`ExpeditionContracts.a_step()` 追踪"谁先看见"，1.0 s 让位窗口、0.62 s 二次注视维持；破戒走 `fail("违反契约A：…")`，熄板 3 s，并把猎手吵醒。

**契约 B ·《锚定厅交接簿 · 手抄页》**
1. 铁网上的每一步都会被井底听成一次呼唤。
2. 连续三声跑动的呼唤而不回以静步，井底会记住你。
3. 被记住后，只有投出会响的东西能换回一次清静；一次远征只换一次。

实现：`b_loud_step()` 每 3 步算一次"呼唤"，3 次呼唤（9 步）→ `b_remembered`，猎手进入 `rage` 判定；节拍器投掷调用 `b_pardon()` 赎回一次，第二次不再生效；站立 1.2 s 会逐年回退未完成的计数。
