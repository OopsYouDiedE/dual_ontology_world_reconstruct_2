# 出征｜每次从公共大厅出发

新局第一帧，玩家已站在 **Public Hall**。手册在身上，两个方向都可查看。可以带居民同行，也可以独自推门出发。营地让玩家先看懂「我带谁、要去哪、想带什么回来」。若以后加入新生报到，只在第一次入营时给一段可跳过的短对话；当前直接开玩。

## 一眼看完整局

```text
公共大厅 → 西1／东1 → 西2／东2 → 折返闸 → 西3／东3 → 天文台晨钟
                                  └→ 营地休整 → 原闸（每局一次）
```

**固定的是站位和大关机制。** 大厅永远是起点；折返闸永远考钟声和拉杆的受力时机；天文台始终考同一套登记、调节与鸣钟装置。分支格也有固定地图坐标。种子决定哪些格之间有门，并从退信室、接线室、泵房、升降房、干燥病房、暗房、调度室七张房牌中取六张，填入三层东西格。每局实际走三张。图中的斜向换线以当局的出口为准。路线图预告房型和收益，玩家在已有连线中选门。

**资源把路线选择变成解法选择。** 西侧取毛毡，适合消回声、防潮、保住箱子；东侧取棘轮，适合锁轴，让适用的慢速操作从 18 分钟缩至 3 分钟。每间机关只装一件，用过从背包扣除。玩家可以在眼前的房间省时，也可以徒手慢走，把工具留给终点。时间和结算物资分别记账。

**折返有明确的代价与收益。** 解闸后可直接进第三层，也可坐一次车回营，补生命、整队，再从同一座闸出发。返营保留背包、已领收益和闸门状态；不会重抽房间或重复发奖。营地里居民按自己的需求活动，出征后行动由队长指挥。

**终点是机关 Boss。** 留毛毡：安装后封存，3 分钟并多保两箱。留棘轮：登记、安装、手摇，3 分钟；空包：登记、手动制动、手摇，18 分钟。三条路都敲同一口钟。固定终点让第二局的玩家有理由在第一道岔路就作出不同决定。

## 房间连接与关卡节奏｜《邪恶冥刻》

采用《邪恶冥刻》（Inscryption）的节点式路线语法：**看到下一步的事件和机会 → 走进某条边 → 完成房间事件并结算 → 再在新位置选路**。在学院里，图上的边落实为第一人称可通过的门；同一节点的符号用于路线图和门前标识。借用的是经过一站、兑现一次选择的节奏。房间内仍是学院的证物、机关和资源取舍。

| 设计层 | 制作约定 |
|---|---|
| 路线节点 | 节点区分补给、规则机关、汇合检查与终局；普通房可兼有机关和收益。选路前可认出下一房的用途与已知物资，谜底留在房内。 |
| 分支和汇合 | 出口选择应改变下一站的规则或收益。各支路在折返闸汇合，再分到第三层，最终抵达同一座天文台。地图上的可用边与实体门一致。 |
| 事件序列 | 大厅定队伍与方向；第一层让玩家获得可花的工具，第二层给出眼前使用与留到终点的取舍；折返闸检查推进与休整；最后一层收束物资，天文台兑现选择。 |
| 生成约束 | 固定三处地标和支路格。种子决定房牌和可选边；所有可选分支都有前进路线，必需线索在对应房内，徒手可解。返营回到原闸，已领取的收益和已消耗的道具保持原状。 |

开一个分支的最小设计稿：**节点用途／入边与出边／门前可见信息／核心机关／徒手代价／使用工具后的差异／离开时带走的东西**。东西线至少各走一次，核对玩家进门前读到的机会和离开房间后获得的状态。单房动线与构图见[布局规范](layout.md)。
