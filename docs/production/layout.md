# 单房与楼层布局｜按空间问题选参考

出征的节点、连线和事件节奏由[路线规范](gameplay.md)决定。本页把每个节点落实成身体能走过去的房间：玩家从哪里看到什么，走哪一段才取得线索，完成操作后从哪道门离开。制作使用 ArchBuilder，先验证尺寸、墙洞、碰撞和视线，再做灯光与陈设。

## 参考库

| 设计问题 | 参考 | 学院中的落点与检查 |
|---|---|---|
| 门前预读与真实门位 | 《蓝图王子》 | 候选房卡画清去向与门位；核对路线图、门牌、实体门指向同一目的地。 |
| 一眼读懂两层及折线走道 | 《巴别塔圣歌》 | 用楼梯踏面、立面与低层分别组织大色面；在泵房入口确认下层操作位和上层出口都能被找到。 |
| 机关与被改变的空间相邻 | The Witness | 从接线室操作位能看到被控制的门，或看到能沿线追到门的反馈；玩家可走回机关核对状态。 |
| 叠层、绕行与汇合 | TUNIC | 先看见目标平台，再沿楼梯或维修道绕到目标；在升降房白盒用同一地标核对起点和回望方向。 |
| 证物分区与调查动线 | 《奥伯拉丁的回归》《金偶像谜案》 | 退信室或暗房用桌面、站位和净空分开调查对象；必读证物靠近动线并在手册保留出处。 |
| 暗处延续方向 | Gloomwood、INSIDE | 用楼梯鼻口、栏杆的剪影、透光门洞续接方向；明度和配色仍按[正式美术](art.md)验收。 |

## 白盒交付件

每房提交一张俯视草图和三处第一人称机位：**入口、操作位、出口回望**。草图标出入口与出口、主路径、可选绕行、必读线索、装置和它影响的对象；标明房牌换到另一位置时允许的门位。按入口→证物→装置→出口走一遍，记录第一次需要停下来辨路的位置。

**折返闸样板**：主路径从入口通到钟与制动柄，两路在装置之后分开；前行口接到下一层，返营口接回大厅。玩家在拉杆前能确认两处门位，操作后能沿地面方向走到自己选定的门，并能从返营路径重新回到闸边。复用这套核对方法到大厅与天文台。

取帧与来源见[参考研究](../research/expedition/README.md)；交付证据见[验证](verification.md)。
