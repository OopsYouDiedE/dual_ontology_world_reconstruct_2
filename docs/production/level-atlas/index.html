METHOD / REVERSE ENGINEERING02 / 12
01 / 读图

把一段实玩拆成三张图

每次选一个问题，例如「玩家为什么愿意离开眼前的门，转身绕路？」先截在决定发生前，再顺走一条路，最后重走并尝试另一条。

图层保留的证据作图与反查
通行 M入口、停步点、楼梯端点、机关、出口；各段实际能从哪里走到哪里。双向写 A ↔ B，落差写 A → B。换层要有对位端点，图面交叉处检查是否真的连通。
视线 V哪个站位、朝哪个方向、何时看见哪件事，是否有足够信息做决定。从眼位 F 连虚线到门、刻度或指示；标窗、栏杆、遮挡和状态。反向再拍一帧。
状态 S谁在何处操作，改变什么，影响哪些边，变化保持多久。用同一组节点 ID 比较 S0/S1。记当前值、前置、失败去向和重置边界。

记录一次选择

版本 / 时间码 / 视点 → 可见选项与线索 → 玩家选哪条边 → 行走、资源和暴露代价 → 到达后确认了什么。给实拍画面与你的解释分别加标签。

动一笔验证解释

擦掉预告窗、封住捷径或挪动操作台，每次只改一项。预测哪一个停步点、错门或回程段会变；白盒中再对照。

示范观察单｜折返闸（依据制作规范）

通行：入口 → 钟与制动柄 → 前行口 / 返营口。视线：拉杆站位应可分别指出两个门。状态：闸解锁后才分流；休整后回同一闸，库存与已领取奖励保持原样。验证动作：遮 HUD 站在柄前，让玩家指回营的门并说出依据。

成本写成一组值：实际步行秒数 / 游戏时钟分钟 / 消耗品 / 风险 / 所得线索。纸上先写相对关系，白盒再填实测值；尺上的短路未必是玩家眼里的轻松路。

阅读依据：Research、Layout、Flow、Parti、How to study a level。假设与观察的分栏、三图共用 ID 是学院交接约定。[1] [2] [4]

PATTERNS / ROUTE OPERATIONS03 / 12
02 / 选型

六种拓扑，六种改图动作

先给体验配一条边，再给边安排形体。一本房牌可以用走廊开场、在中厅展开绕路、在出口前汇合。

走廊 / Corridor

沿链顺序揭示征兆、演示与后果。转角控制先读到的东西；加凹室可供停看。

折线 / Hairpin

让去程遮住一个出口，回望时揭开。若尽头无可发现之物，把折角缩短。

枢纽辐射 / Hub-and-spoke

中心负责定向与比较，支路各给不同兑现。频繁回中心时，让状态也随回访更新。

绕核场地 / Bowl、Arena

在中央体块两侧留可走面。两边能看见的证物、目标或风险各异，才值得选。

分支再汇合 / Branch & merge

从同一决策点分两路，再接一个共用检验。让选择改变取得的工具、信息或到场顺序。

回环与捷径 / Loopback

从深处接回起点或旧路；先见梯脚，再从上端放梯。开通后用一次回程兑现。

叠两个独立选择：连房间与看房间分别落笔。把窗开进回环可预告对岸，却保留绕路；再添加跨层楼梯才会改变步行图。多层图用同一朝向、标高和梯口编号。

小公式｜一次连接增加几种走法？

冻结门态，将双向通行画成无向图。连通区域的独立回路数 = 边数 − 节点数 + 1：沿链加一个新房，只拉一根线，回路数不变；在两个已有房间间开一条新边，回路数加一。把新旧走法的耗时、所见和风险写在图旁，决定那条边值不值得做。方向门与动态门按第 4 页检查。

本页把书中的房间、关卡类型与学院常用的合流动作并排使用。Hairpin 强调回头才看到出口；习惯上称「回环」的走廊也可由脚本重置，分析时标清真正的边。[2] [3]

GATES / REACHABLE STATES04 / 12
03 / 状态

每道门都有条件、反馈和复位

画完地图后，用棋子把「我站在哪」和「此时能走哪条边」一起推进。先测最贫穷的初始状态，再把道具和伙伴加回去。

门控学院用法纸上验收
硬门机关没完成就关，如 V 扳杆控制出口 D。从入口可到 V；在 D 识别关闭，从 V 确认开启，开后能到 D。
软门 / 代价徒手可过但更慢；包里的工具换时间或收益。同一起点用空包和带工具实走，分别结算；工具消耗后仍可继续。
方向门深处放梯后双向开；下落口只能往下。画单向箭头。逐条检查落地后的恢复路，以及逆向逼近时的读图。
知识与时机先在安全位置观察征兆，再做跨越或同时动作。在危险前能观察一轮；预判错误有明确后果与回收站位。
判定规则：站位 × 门态 × 剩余资源 × 必需事实 × 一次性标记 → 可执行动作 → 新状态

一张连通图，两个完全不同的结果

初稿：入口 ↔ 岔口 → D[钥匙] → 储物间[拿钥匙]。普通连通检查会穿过 D；按状态走，棋子只能到岔口。改稿：把钥匙挪到岔口的可达支间，或把支间改成纯奖励并给 D 一个可达的徒手操作点。重跑从岔口沿每条合法单向边出发的情况。

判定一｜存在解

用队列搜状态。初始状态入队，枚举可走边和操作，跳过已访问状态；遇到出口就保存动作序列。每个合法入口 × 空包独行各跑一次。

判定二｜失败后还能解

从终局沿已生成的状态转移反向标记；正向可达但无法抵达终局的存活状态，给出失败路径。检查掉落、道具耗尽、单向边和返营次数。

Gates、Critical path 提供门控与主路径语言；展开有限状态与反向走查是学院的测试办法。[3]

CASEBOOK / FROM DUNGEONS TO IMMERSIVE SIMS05 / 12
04 / 真实案例

拆出一条能移植的边

以下用文字拓扑追踪公开案例中的局部路段。每个案例只提取一个可在学院白盒里验证的动作。

01　Caverns of Thracia｜给两层交叠的洞室留接点

作者证据：Jennell Jaquays 在访谈中谈到让开阔的上层洞室位于开阔的下层洞室上方，让遭遇跨越两个高度。这条方法线在早期桌游地牢已出现。Justin Alexander 后来公开了自己重排 Keep on the Shadowfell 的前后图：用同一批遭遇验证连接方式的改变。[5]

移植：先保留机关和证物，试画「一层 H → 西梯 → 二层 V」与「二层 V → 东梯 → 一层 H」。玩家在两层都能认出同一个地标；删掉东梯，比较回程与探索选择少了什么。

02　Dark Souls · Undead Burg｜可丢掉的探索回路

逐段证据：手册实玩拆解标出主线 1→2：近楼梯、过桥、到雾门。站在雾门附近能向下看到战利品；可选线 3→4 是掉下去取物、穿屋爬梯、从城墙落回熟悉的楼梯。高处先给方向，回程重认地标；不下去也可继续主线。[6]

移植：东廊让补给吸引人下楼，下层再把玩家送回能看到出口的中庭。白盒反查：移除补给，空包主线仍通；保留补给时，从打开柜子的位置能指出回路的下一段。

03　Prey: Mooncrash｜把状态生命周期画在地图旁

开发者证据：Arkane Austin 关卡设计负责人 Rich Wilson 的 GDC 图稿第 53–60 页连讲多角色、持久化与模拟重置，第 87–91 页单列逃离方式。读图时把同轮换角和重置模拟画成两条不同的时间线。[7]

移植：给每项操作声明保留范围。「梯子放下」「闸已开」「奖励已取」分别记一次。伙伴到了可以走已放的梯；正式出征返营后继续读原闸状态；新局才初始化。对照首访、折返和新局三个存档点。

复做练习：拿一张现有房间草图，先固定站位与事件，只允许增删一条路、一条视线。写下预期变化，再请一人按图指走。出现新停步点时把原因和位置写回图纸。

三款参考，各管一个尺度

一项选择的完整节拍：预告（我能选什么）→ 练习（在安全处看见规则）→ 承诺（过门或跨桥）→ 反馈（物件或门在变）→ 兑现（奖励、捷径或新路线）。节拍慢时先找重复往返，快时看玩家是否来得及读征兆。[1]

重玩专查｜哪些路只值得走一次？

同种子换路再走，把每段折返标为「取得新事实」「改变状态」「只搬运」。若玩家已知道解法却频繁回发令点，试把发令点搬到看得见作业面的站位；观察理解是否保留、纯折返是否缩短。

PRODUCTION / TWO TOPOLOGY SCALES07 / 12
06 / 接正式出征

固定大关，变量留在房牌和边

从公共大厅出发，固定折返闸检验推进，固定天文台兑现一路选择。先在一张房牌内部做出有效绕路，再考虑全局加边。

改动层必须写进房牌或验收单
跨房端口入口/出口边位、方向、连接标签、允许的镜像或旋转、门前预告。对照 HouseMap、路线图、门牌，以及相邻房真实墙洞；关掉可选边再测。
房内必要解合法入口都能独行、空包到出口。障碍所需的证物放在本房可达区，奖励、工具和队友扩展选择。营地由居民自主决策，出征中由队长指挥。
结算与返程写出取得、花费、保留资源以及对下一站的影响。折返只一次，背包、领奖和闸状态保持；晨钟复测毛毡、棘轮、徒手三格。
两重可达拓扑求解器查端口匹配和起终点连通；关卡另查条件门下的真实推进。用不同种子、合法端口组合和空包，确认任何合法出路都有推进或恢复路径。

制作基准与代码入口见 路线与事件、拓扑模块、正式验收。[10]

WORKFLOW / FROM PAPER TO BLOCKOUT08 / 12
07 / 造图工序

六步把纸图交给白盒

先锁玩家要做的决定，之后逐段增加制作成本。每一步都交一样能让同事继续工作的东西。

工序动手做带什么过评审
① 一句构想
Parti		写「先从楼下看见锁，绕上楼开锁，再从近处回到那扇门」。圈入口、最终目的、一次回看。同事只看简图，复述空间体验与要做的选择。
② 节拍与主路径先连最小徒手链，标入场预告、首次操作、反馈、离场。给链加一个可略过的探索回路。删除可选线路，用棋子仍能走完全程。
③ 拆图与试方位画楼层和剖面，叠三层图；给窗、边与机关编 ID。两路至少比较一种真实代价。A/B 两张小图；指出各自第一个疑惑点，选一张进白盒。
④ 标尺先行在基准白盒测角色眼位、门净宽/净高、拐角、楼梯落脚、操作射线、队友交会、窗后遮挡；用 ArchBuilder 接墙洞、楼板、梯、栏与窗。表上写「候选尺寸 → 实测 → 选值理由」。用角色、镜头与碰撞核实标尺。
⑤ 最小交互版只实现必经操作、结果反馈、可选捷径和回收。先用占位灯与形状，玩家文字用英文并与门牌统一。每条状态边可复现；入口、操作点、回望分别截图。
⑥ 试玩后再细化独行首测，再跑同种子换路；只改一个变量复测。随后补材质、音响和室内氛围灯；时间光由外窗进入。一条观测、一项修改、一轮对照；按第 11 页分别签逻辑和实机。
先走四个易漏位置：门槛同时站两人，梯顶转身，栏杆前看下层目标，控制台贴身操作后立即抬头。一个位置同时测试身体通行和相机读图。

流程来自 Layout、Parti、Blockout、Metrics、Wayfinding、Playtesting 的组合；灯光和工具按学院制作约定落地。[2] [4] [10]

GAUGE HALL / WHITEBOX PLAN09 / 12
08 / 原创练习 · 待白盒

表盘桥厅：先看见门，再改写回程

场地构想：进中庭 H 看见挡杆 D，从安全西梯或短桥到上层闸杆 V。开闸后可从近处放梯，看着同一只表盘返回。

首轮摆件用身体与相机检查什么
A / P / C / S西梯试 2.0 m 净宽；中央桥试 1.5 m。标高先用 +3.2 m。梯脚、净空、栏杆、回望均按实际控制器重测。
W1 / W2 / H室内窗和栏杆先挡身体、透视线。W1 能完整看到灯灭、收板、复位；V 站位透过 W2 看到 D 挡杆升起；两层都能认出 H 的表盘。
X / R / G桥下做截落的平台与回收坡，坡尽头回 H。G 是东廊可错过的补给柜；开柜后看得见回 H 的方向。
GAUGE HALL / STATE SHEET10 / 12
09 / 机关交接 · 初版假设

三条走法，同一扇出口闸

西梯稳定，中央桥短但有时限，东梯可取补给。即使先去摸门、桥上失手或忘放梯，仍能推进。

常驻边：E ↔ H ↔ A0 ↔ A1 ↔ V ↔ C1 ↔ C0 ↔ G ↔ H；
H ↔ P0 ↔ P1；V ↔ S1；H ↔ S0；H ↔ D；R → H。
事件 / 初态触发与反馈之后可以去哪里
V · 闸杆
gate=closed		在 V 单次锁存开闸，W2 可见 D 挡杆升起；未开时反馈 Gate Locked。gate=open 后 D → 下一房；D 关闭时可退回 H。
S1 · 放梯
ladder=stowed		只在上端拉绳，锁存放梯；下端可看空挂钩，上端可看梯落位。ladder=deployed 后 S1 ↔ S0。A / C 仍通。
X · 观察桥
charge=0..3		W1 的样机演示与桥的通行独立。P1 的可选灯临时点亮反光标；持续看准才维持桥板，每跨一段耗一格，三段到 V。只从 P1 入桥，零格时显示 No Charge 并留在 P1。跨桥途中电尽或失焦则坠 R → H。末段先判抵达 V、再判电尽；V 侧挡板禁止逆行。
G · 补给柜
claimed=false		在东廊领取一次打包物，打开后保持开盖；补给与桥灯分开。继续沿东梯或回 H；回访读已领取状态。

A / 徒手

E → H → A0 ↑ A1 → V；先开闸再放梯，S1 ↓ S0 → H → D。也可不放梯，从 A 或 C 回去。

X / 熟手

E → H → P0 ↑ P1；有三格时跨 X → V 开闸。仅两格或中途移开视线：落 R → H，改走 A。

C / 探索

E → H → 东廊 G → C0 ↑ C1 → V 开闸。折返东廊时柜子仍开，也可用已放的 S。

保留：V、S、G 和剩余电量分别锁存于本局该房状态；重新读入同一房实例时保持，新局清零后按用例设种初始电量。房牌首次落位可用空电或三格测试档。E 仅进、D 仅出；提案先做双端口白盒。接入多出口的槽位时需另做门组，逐一重跑逻辑、首帧与出口朝向。

REVIEW / OBSERVE, CHANGE, RETEST11 / 12
10 / 验收

把一次试玩记成一次改图

先让第一次见房的玩家独行，观察员只记站位、视野、动作。离场后追问当时以为会发生什么。同种子换路重走，衡量已知解法后的纯折返。
