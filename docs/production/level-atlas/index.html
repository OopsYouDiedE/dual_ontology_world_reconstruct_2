01　/　读图

先画出玩家的决定

在泵房门口，玩家看见对岸的闸。左边是能看清闸灯的楼梯，右边是贴着水管的短桥。要让这次选路成立，两条线得让玩家承担不同的代价。

工作顺序　　拆一段实玩 → 画三张图 → 指走一遍 → 进引擎核对视点
同一个关卡，描三遍纸上保留什么用它回答什么
步行图圆点是停下来做决定的位置；实线是可走的边，箭头标方向。封住最短边，还能从哪里到达？
视线图虚线从眼睛连到物件；写明隔着窗、栏杆还是挑空。做决定之前，哪条信息已经到手？
状态图复制步行图；操作后只重描开、关或换向的边。同一扇门第二次经过时，有何新用途？

按尺度选结构

走廊适合让人按顺序看到征兆与后果；枢纽适合比较目的地；回环把两处旧空间接成新路线。三条路都必须由大厅原路往返时，图是辐射形；把其中两条的远端接上，才出现可绕行的一圈。参见 Typology 与 Circulation。

学院在哪一层使用这套方法？

大地图从公共大厅出发，营地、折返闸和天文台保留原位置与机制；种子替换沿途房牌与可选连线。以下练习发生在一张候选房牌内部。画完内部回路，再把入口、出口接回房牌声明的门位。

02　/　案例档案

五个关卡，五种改图动作

拆案例时保留三件事：玩家原先能去哪，什么改变了选择，以及把同一手法移到学院时，要改哪一条边。

01　《杀手》｜给边界开不同用途的孔

迈阿密 · GMTK 访谈 IO 设计师：比赛把人引向公共看台，工作人员却需要往返维修区。把这些身份画在同一张图上，同一扇门就有了不同的通行代价。对照萨皮恩扎制作访谈，沿街道找别墅边界与侧面入口。学院练习：主门给最清楚的目标视线，维修梯给较低的暴露；分别写出谁会选它。

02　《掠食：月陨》｜让上一个人的动作留在地图上

Arkane · GDC 演讲图稿：一轮模拟中，不同角色接续逃生；工程师修好的设施能改变后来者的选择。分别画「换角色」与「重置模拟」两条时间线。学院练习：队长先放下维修梯，让后到的队员从下层赶来；在状态表写明梯子保持到何时。

03　《梅祖拉的假面》｜只重画发生变化的边

GMTK · Boss Keys 原作分析：海湾神殿的水轮与中央水流相关。反转水流后，从同一水室可以顺流进入另一组通道。描两次水室，保留房间位置，只换通道箭头。玩家记住水室的布局，就能预测下一步；学院的配电线也应允许这种预测。

04　《网络奇兵 2》｜让修复设施改写返程

工程甲板恢复动力后，主电梯接回航路。去程的任务对象成了后来往返甲板的交通工具。拆图时分别描出修复前的步行段与修复后的电梯站点。工程侧可对读开发团队 1999 年复盘中关于关卡构建成本的回顾。学院练习：先在梯脚发现空挂钩，稍后从上层放梯，马上用它回到原处。

05　Jennell Jaquays 的地牢｜保留遭遇，改两处连接

Justin Alexander · Shadowfell 改图前后对照：作者保留原遭遇表，重接楼层和入口，并引述 Jaquays 对上下洞穴交叠的设计意图。纸上复做：把 A—B—C—D 折起，加 A—C 的高窗、D→B 的落梯。窗让玩家预判 C，梯让玩家跳过回程的 C；分别擦掉一笔，检查损失了哪种选择。

03　/　重玩成本

第二次来，还会怎么走？

让同一位测试者再走一遍。第一次的犹豫可能是在读建筑；第二次仍然耗时的地方，往往更值得动刀。

案例 A　固定目标把人拉回了同一间地下室

在纽约银行制作访谈 · 约 16 分钟里，设计师谈到萨皮恩扎病毒目标带来的重复感。纽约的任务保留取数据这一意图：玩家可以进入金库，也可以从人身上取得备份盘。两种做法改变了玩家关注的对象：一个读建筑，一个读人的动线。

学院改图　把选择放在固定终点之前

天文台仍是同一座，终局仍敲晨钟。先在沿途测试房给同一闸门准备两种抵达操作台的方式：新玩家沿安全梯观察灯号，熟手读懂桥的征兆后直接穿过。回放第二局，标出玩家靠已有知识省掉的路段。

案例 B　Witchyworld 的碰碰车为什么显得远？

Mark Brown 的 Banjo-Tooie 拆解逐项列出了这段路：换 Mumbo 给设施通电，换回主角，再变成厢式车去付费，最后恢复主角才能游玩。玩家早已理解解法，余下的工作是反复往返角色切换点。这里记录的是评论者的分析。

学院改图　把口令放回发生选择的位置

在控制台放一个可俯瞰桥面的指挥位：队长在此下令，队员原地应答。独行则走旁边有掩护的楼梯。观察员把每次折返记成「获得新信息」「改变状态」「仅换人」；出现连续两次仅换人，就把发令点挪到作业面重测。

评审问句　　删去一次往返之后，玩家失去了哪一个判断？若说不出来，先试删。

04　/　绘图工序

用四步画出一张可测的房牌

纸、两种颜色的笔、两枚棋子就够。每一步结束前，请旁边的人沿图走一遍，让他指出自己下一步想去哪。

①　定两端，再接三路　｜　产出：步行图

圈出本房的中庭 H 与远端操作台 V，给 H 放一只两层都能认出的压力表。在 H、V 之间画西梯、中央桥、东廊。把棋子从西梯送上去，再沿东廊送回来：玩家第二次回到 H 时，应从另一侧认出同一块表。闭合后再加一条由 V 放下的直梯，形成第三个独立回路。

②　把目标放进视野　｜　产出：锁钥与两帧

在 H 旁画出口 D；把解锁杆放到二楼 V。入口机位先看见闸上落下的挡杆和灭灯；操作位透过 W2 看见同一挡杆抬起。多条件版本给每个条件一根有编号的管线和一盏独立灯。用棋子模拟从每个合法入口进房，查谁会先摸到解法。参照 Gates。

③　先凿观察孔，再放压力　｜　产出：规则交会点

W1 只透视，仍挡住身体。从窗外先看桥板亮起、缩回、复位一遍。规则 A：观察桥面标记时桥板保持展开；规则 B：手灯在桥上耗电，熄灭后标记难辨。两条规则只在 X 叠加。新手可退回门槛，改走西梯；熟手可估算电量直接上桥。掩体是否挡视线、是否挡身体分别标注，见 Cover。

④　从深处放梯，把奖励留在外围　｜　产出：状态图

在 V 拉绳，从 H 挂钩处放下直梯；以后双向可走。东廊挂一个可错过的电池柜 G，支线终点让玩家转身看见回程楼梯。拿走 G 棋子后独行重走主线；仍能开闸才交图。最后只给 ArchBuilder 门洞、楼板、玻璃和楼梯的位置，先查碰撞与视线，再补陈设。

05　/　原创图纸 · 待白盒验证

表盘桥厅 / Gauge Hall

双层房牌练习。两图上北下南、楼梯同位；走廊用双线画，蓝虚线仅可看，棕色短线为出口闸。尺寸是首轮摆件起点。

构件摆法与反馈
A / B / C自西向东三组楼梯上下对位。以 2 m 净宽摆西梯，中央桥试 1.5 m；东廊绕电池柜再上楼。橙点标定位，不是阻挡。
W1 / W2W1 设在 H 西肩，朝东北看 X 的收板示范；W2 设在 V 东南窗，斜向下看 D。V 与 H 同轴叠放，窗下给视锥留挑空。
V / S / DV 控制 D：Closed → Open。S 的绳只在上端可操作：Stowed → Deployed，随后双向通行。两项独立，整次访问保留。
用手指走　　空电独行：入口 → H → A ↑ → V 开闸 → S 放梯 ↓ → D。
熟手：H → X → B ↑ → V；贪心路线：从 C ↓，取 G，再回 D。

06　/　评审与交接

把一次试玩记成一次改图

先让陌生玩家独行；第二遍请他换条路。观察员只记录站位、看到的东西和接下来的动作，走完再问理由。

走查条件观察 / 通过信号失败先改什么
初见、合规入口种子各一局入门先指出 D；经过 W1 能描述桥板变化。转动门框或移动观察窗，复查首帧。
零电、独行、跳过 G走 A，启动 V，能从已开放的 D 离开。移开主线上的物资门槛。
桥中耗尽电量桥下接安全坡回 H；同一存档可再走 A。加回收平台，封住会卡人的缝。
双人、两层各站一人在 V 能看清 D；队长就地下令，楼下有可辨回应。挪指挥点或给灯加形状反馈。
重玩，先开闸、暂不放梯可由 A 或 C 返回；放梯后回程明显变短。拉开远路与直梯的距离。
换房牌或删掉可选连线从公共大厅到固定终点仍可达；折返闸返营一次后可续行。区分房内边和大地图边，恢复必需连接。

白盒取证

用 ArchBuilder 放门框、窗洞和双层楼板。先以角色眼高检查 W1 和 W2，再用项目游戏 MCP 在真实 Forward+ 视口留三帧：入口看锁、阀边看灯、出口回望表盘。日照只从外窗进入；W1/W2 是室内观察窗。逻辑检查另存种子、门状态和路径。
