# 关卡与美术的取帧依据

《蓝图王子》（Blue Prince）主导第一人称渲染，《巴别塔圣歌》补充建筑色面与纵深导向。《邪恶冥刻》（Inscryption）主导分支连接和事件节奏，其余作品用于解决单房和楼层里的具体布局问题。以下是对 Sol 取帧材料的复看；制作约定见[美术](../../production/art.md)、[出征路线](../../production/gameplay.md)与[单房布局](../../production/layout.md)。

| 看哪一帧 | 画面中能看到什么 | 学院采用的做法 |
|---|---|---|
| 《巴别塔圣歌》连续实玩 03:02 / 03:14 / 03:26 | 黄阶梯、红墙和水渠把通路、边界、下层拆成三大片；小人物仍有清楚的位置。 | 先在房间入口画出三大片，再放门、钟与人。 |
| Blue Prince `blue-alt1-30.jpg` / 00:36、`blue-alt2-48.jpg` | 房间候选有不同边框、门向和内部轮廓；近看可读方位物件。 | 门前预读下一房；纸面符号与房里实物形状对应。 |
| 《邪恶冥刻》Notlad 01:02–01:42；《杀戮尖塔》00:15 作同类对照 | 从平面节点进入木雕事件；分支节点的符号先于事件出现。 | 路线图先预告房型与收益，再让玩家确认出口。 |
| 《金偶像谜案》00:05 / 00:25、《奥伯拉丁的回归》00:18 / 00:23 | 前者从物证转入陈述；后者密集索具旁留出整片甲板。 | 手册保留证物出处；铭牌背后留空，门比墙缝更醒目。 |
| The Witness 00:10、TUNIC 00:42、FTL 连续实玩 01:38 | 门前的线路、高低道路和交战中的投降报价分别与现场状态并置。 | 操作结果在机构上显现；报价时仍能看见背包。 |
| Gloomwood、LIMBO、INSIDE、BELOW、Darkwood | 阶边、逆光梯子、平台和局部照明能跨镜头延续方向。 | 把阶边和剪影用于低照度导向；曝光与色面以《蓝图王子》为主。 |

**如何复核。** Sol 的清单覆盖 14 款游戏、18 段商店视频和 3 个连续实玩窗口。商店片段按镜头取样；连续窗口分别是 [Inscryption / Notlad](https://archive.org/details/inscryption-ep-9-not-again)、[Chants of Sennaar](https://archive.org/details/20260824_20260824_2151)、[FTL / boneofhead](https://archive.org/details/PC_Longplay_380_FTL)。[来源清单](sources/)记录公开页面、视频与帧时间；[帧索引](frames.csv)记录 194 张帧图、13 张联系表和各自 SHA-256。路径以本机 `.runtime/sol-level-final/` 为起点，补录在相邻的 `sol-extra-live/`。图像统一为 1080×720 JPEG，保留原构图的留边。外部帧保存在本地研究区，游戏包仅收自己的资产。
