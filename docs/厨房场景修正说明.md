# 厨房场景修正说明（B-P 乙区小厨房）

基线：`6b2f552 Fix Godot game UI readability, lighting and room assets`；引擎：Godot 4.7.2-stable（标准版，软件渲染下实机截图验证）。

## 在真实场景里看到的问题

1. **交互模式断层。** 卧室（第一幕）与走廊（第三幕）都是「无顶栏 / 无左卡，点发光物件或靠近按 E，Esc 唤出完整界面」。
   走廊一走进厨房，立刻变回完整界面：顶栏、左卡、证物列表、出口按钮、7 根黄色光柱，没有 E 提示和操作提示。
2. **移动与镜头不一致。**
   - 厨房镜头被硬切成 `pitch=1.25`、`az=0.65` 的近垂直俯视，而 `WASD` 按世界坐标移动，所以按 W 在屏幕上是斜着走。
   - 右键拖动转视角后，方向与屏幕的偏差还会继续变化。
   - 台词一出现，WASD 完全失效（实测按 W 1.2 秒位置不变）。
   - 撞到家具 / 墙直接「粘住」，不会沿边滑。
   - 侦探从走廊进来时直接出现在房间中央，没有走进门的过程。

### 视角转换

进厨房时镜头沿用走廊的角度（`az=0.12, pitch=1.0, dist=7.4`），在最初 2.5 秒内平滑过渡到跟随镜头（`pitch=0.95`，距离随房间取景，焦点在房间中心与侦探之间）。之后滚轮和右键拖动归玩家。

### 移动方式

屏幕「上」= `-(sin az, cos az)`，屏幕「右」= `(cos az, -sin az)`。`az` 为任何值时，W 都沿屏幕向上。

> 这一条改在 `_manual_move_step` 里，同样会影响卧室（那里 `az=0.65`，原来同样是斜着走）。az 接近 0 时与旧行为一致。

## 验收

```bash
xvfb-run -a godot --path . --rendering-driver opengl3 -s tools/test/kitchen_flow.gd -- out=.runtime/screens/kf scale=4.0
```

结果 `RESULT fails=0`。检查项：无顶栏 / 左卡 / 抽屉；7 个宝石；原版光柱隐藏；侦探从门口走进来；az 取 0.12 / 0.9 / -0.7 / 2.2 时 W/A/S/D 方向与屏幕一致（dot=1.00）；台词期间可移动；贴障碍斜走会沿边滑；靠近按 E 与点击走近都能取得证物；Esc 切换完整界面。

## 首题行为复演补充

同一厨房首题后来加上了 `ded_drag` 的四段动作复演：仅在四件相关证物齐全时接管推演，记忆角色演出扳门、拉回、塞布、反扣四个动作；玩家排序后才将正确结论交回 `DualEngine`。复演错误可留在现场调整，不会写错案卷。厨房名牌只在鼠标悬停时显示，底部保留一个现场线索计数。

离开 B-P 转入剧情中的 A-P、C-P 等房间时，厨房专属漫游、标记与提示会先清理，再由常规转场重新载入对应实景。详见[开局至四区首题：行为推演与场景连续性修正](厨房推演与剧情连续性修正说明.md)；相关验收脚本为 `tools/test/kitchen_order_replay.gd`、`tools/test/first_four_questions_flow.gd`。
