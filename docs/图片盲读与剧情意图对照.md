# 主线图片盲读与剧情意图对照

页面入口为 `artifacts/review/index.html` 与 `gameplay.html`，带图文本为 `artifacts/review/评分总览.md`。各段按正式主线顺序展示：实机序列、图片盲读结论、修改次数、动作与意图分别得分、测试者原话、目标动作／意图、当前实现、具体差异和下一次修正。完整实机七项验收保留独立状态。

2026-11-16 本轮补采走廊真实生产演出19帧，覆盖出门、停听、靠近、加入、九句对话、结束过渡与自由探索，使用原速。启动与截图回执包含项目身份、实际PID、源文件指纹与结束快照。图片记录位于 `artifacts/acceptance/corridor-story-20261116-v2`。

独立 Terra 图片盲读使用 `visual-blind-20261116-v3/input.json`，11段93帧。测试者只读取匿名图像清单，叙事文字已遮罩，场景名牌保留；没有读取剧本、源码和答案，没有音频。第一轮遮罩了名牌，发现人物被挡后，保留旧输入与原始判断，另开全新 Terra 重测。两轮资料分别在同级 v2、v3 目录。

评分由主智能体在获得原始盲读后逐项目标对照：相符10、部分相符5、误读／漏读0；动作和意图分别取均值，两者均达8分为图片盲读合格。测试者自评的“可读性”单独列示。具体脚本设定、测试采样缺口和画面表达不足分别写入实现与差异栏；漏采导致的低分明确记录为素材覆盖问题。厨房两段目前采用历史开发关键帧，页面保留来源说明。

本轮走廊动作一致度3.3，意图一致度1.7。独立观察者识别了行进、靠近和伸手回应，把四人误读成三人、交流读成盘问或冲突，且把自由探索标记读成事件结算。共同失忆、湿袖／破袖、工具箱、残页与手背抓痕都未被辨认。下一轮先补停听和临时加入节拍，再按单变量纪律逐项补身体／随身物件展示与厨房方向引导。

结构化对照通过项目 MCP `semantic_append` 追加到 `artifacts/acceptance/semantic_reviews`，每次生成检查事件，完成后另加确认；整批闭环调用 `render`。完整格式见 `mcp/review/README.md`。源码指引快照保存在本轮 `truth-sources`，修改代码后仍可回看当时设定。正式标题新游戏的七项验收继续使用 `review_append` 的原有独立实机门槛。
