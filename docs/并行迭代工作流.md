## 短回归

```powershell
.runtime/python/Scripts/python.exe tools/testing/run_parallel.py --workers 2
```

执行器按清单启动独立的无头 Godot 进程；每个任务使用独立输出目录、日志、PID 与启动回执。默认固定步长为 60，适合状态、骨骼接触及结构回归。遇到脚本错误立即结束该任务，超时也会回收自己启动的进程。并发数可在 1 至 4 之间选择。

默认清单 `tools/testing/fast_checks.json` 包括旧/新人物接触参数对照、全部 YAML 配置与 Mock 状态校验、64 种建筑组合结构检查。清单可加入其他模块的独立 GDScript 探针；执行器统一传入 `--test-output`，保留原有证据。

固定步长无头结果按 `headless_fixed_step_development` 归档，`acceptance_scored=false`。画面、声音、帧时间和美学评分继续来自 Terra 实际运行采集。

## 画面采集与整批复核

角色/物件/动捕的数值检查稳定后，统一执行短片段画面复采。需要测真实帧时间时，暂停其他 Godot 与重型 CPU 作业，单独运行一个采集进程。稳定批次再执行完整流程采集、独立视听盲测和参考图对照。

报告批量导出命令：

```powershell
.runtime/python/Scripts/python.exe tools/testing/export_review_site.py
```

入口为 `artifacts/review/index.html` 与 `artifacts/review/评分总览.md`，原始回执和报告继续保留。

## 版本内容

每个 `main` 版本包含该批模块代码、配置、必要参考资产、回归工具及状态说明。提交信息说明可运行行为与实际验证；已知缺陷明确记入实施状态。原始采集、缓存、运行日志放在已忽略的 `artifacts/` 与 `.runtime/` 中。其他来源的临时文件保留在工作区，由其所属任务处理。
