# 建筑器优化说明（结构生成 · 家具 · UI）

实施与验收记录见 [33 实施与验收](33%20实施与验收.md)。

## 1. 结构生成

| 项目 | 改动 |
| --- | --- |
| 房间拓扑 `RoomTopology.gd` | 图节点改用空间哈希按容差（2 mm）合并，浮点噪声不再把同一交点拆成两个节点；线段求交先做包围盒剔除；悬空枝杈改用工作表剪枝；偏移地板轮廓增加斜接上限，斜接失败时回退到 Clipper 统一偏移，尖角不再让整个房间消失；每个房间新增面积、周长、质心、相邻房间、外墙边数；忽略小于 0.04 m² 的碎面。 |
| 墙体几何 `WallPathGeometry.gd` | 墙段两个长面分别计算端点，相邻墙以**任意角度**做斜接，不再依赖固定裁切量加方形立柱；斜接过长或墙段过短时退回平头 + 填角块；立柱、顶线帽按相邻墙段方向旋转；斜接区不放门窗，门窗仍在内侧范围内切洞。 |
| 门窗数据 `ArchitectState.gd` | 插入墙节点、删除墙节点后，门窗按平面位置重新绑定到最近墙段（原先索引错位或被丢弃）；放置门窗时避让已有门窗，墙段放不下时给出提示；新增吸附函数 `magnet`、墙面吸附 `wall_snap`、`room_at`。 |
| 数据健壮性 | 导入/撤销时 `sanitize` 补全缺失字段：门窗类型与尺寸、楼梯默认值、栏杆、家具 `params`（原先缺 `params` 会在重建时报错）、墙高墙厚范围。 |

## 2. 家具

- **网格合并**（`Geo.bake`）：每件家具的多个静态盒体合并为一个网格，按材质分表面；灯光保留。
- **失效参数修复**：`lamp_energy` 现在驱动灯光强度；`mount_y`／`lamp_height` 在放置时转为挂高（原先壁灯、画会落在地面）；`crate_tier` 控制木箱堆层数；`lectern`／`chalkboard`／`upright_piano`／`easel` 原先落入占位立方体，现在使用已有的原生配方并响应对应参数。
- **新家具**：沙发、床头柜、圆桌（含参数预设）。
- **占地模型** `PropFootprint.gd`：每种家具的平面占地、前向、安装类型（落地／挂墙／台面／吊顶／地毯），2D 与 3D 使用同一参数。
- **自动布置** `AutoFurnish.gd`：卧室、书房、起居室、餐厅、储藏室五套模板。背靠墙面、检查房间轮廓与门洞净空、检测同层落地家具重叠，椅子面向桌子，床头柜靠床头，吊灯居中。清理按家具底部所在图层归属，不删除相邻楼层家具。

## 3. UI

- 2D 蓝图：家具按真实占地的有向矩形绘制，前沿加粗标朝向，挂墙/台面/吊顶用不同颜色；重叠或出界的家具标红；房间名称与面积；选中墙与绘制中显示长度/角度；绘墙时吸附到已有节点或墙中线（T 接头），非当前图层的墙变淡；命中检测改用占地矩形，小件优先于桌面。
- 工具栏：选择／绘墙／地板／门窗／栏杆／家具切换按钮（当前工具高亮）；快捷键 V W O P F、方向键微调（Shift 加大步长）、Ctrl+D 复制、Ctrl+Z／Y 撤销重做；右侧实时显示坐标、所在房间面积、吸附步长。
- 放置家具：靠墙家具和挂墙物自动贴墙面并朝向室内（按住 Alt 关闭）；拖动家具时同样吸附。
- 新增“自动布置”页；组件库改为可搜索列表；原生组件的参数可在检查器中编辑；检查器的数值编辑不再重建面板（输入焦点不丢失）。
- 3D 增量重建：只重建数据变化的构件，拖动时每帧至多重建一次。
- 修复 `view_mesh_shown` 里不可达代码、房间页在房间数不足时的越界。

## 已知边界

- 合并网格增加首次载入的计算成本。
- 内院孔洞、复杂自交轮廓仍未支持（与原文档一致）。
- 自动布置是规则布局，不做全局最优搜索；极小房间只会放下部分家具并提示。
