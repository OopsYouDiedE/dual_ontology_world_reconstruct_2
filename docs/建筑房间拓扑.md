# 建筑房间拓扑

同层墙网决定房间。墙记录中线、厚度、高度、节点和洞口；房间记录有界闭环、节点及相邻墙。共享墙同时属于两侧房间，两侧各使用该墙朝向房间的一面。

墙端点、T 接头及交点是房间轮廓节点。端点落在其他墙段内部时，房间图自动切分该墙段。编辑该接头时，宿主墙实际插入节点，并更新洞口所在墙段及沿墙距离。节点的批量移动使用修改前的统一快照，避免相邻节点连续移动时互相覆盖。

房间地板由中线闭环按逐边半墙厚向内偏移得到，转角使用相邻偏移边的交点。绘制铺装时进一步裁剪到地板轮廓。门窗属于墙，开洞不破坏房间闭环。

移动墙、节点、修改墙厚或删除墙后，重新计算同层房间。断开闭环即失去对应房间地板；删除中间隔墙使两侧空间合并。房间轮廓节点与墙网共用，不能把派生地板顶点单独移离墙面。拖动整个房间时，其轮廓关联的墙节点一起移动，并同步相邻房间。

没有闭环的剖面图可以保留手绘地板。首次形成闭合墙网后，该层地板由房间派生，不再使用独立地板轮廓作为房间边界。由独立地板建墙时，中线外移半墙厚，使墙内面贴合原地板边界。已有派生房间不重复向外生成墙环。

层、墙、洞口和派生房间数据共同进入 JSON／YAML 与撤销快照。Godot 候选导出使用当前派生几何。

房间预设保存完整闭合外围墙，默认显示全部墙段。F01 的中间平台与上层回廊作为独立楼面保留，不对这些楼面另行封闭围墙。

“显示／隐藏”窗口按类别、单段墙和单个地面、楼梯、栏杆、家具控制 3D 可见性。墙段的门窗随该段显示；相邻两段均隐藏时，共用装饰柱也隐藏。此状态独立于建筑数据，不改变二维蓝图、房间拓扑或撤销快照。实体与线框遵循相同可见性；JSON、YAML 和 Godot 候选均输出完整结构。“全部显示”恢复所有构件；载入预设时也恢复全显。
