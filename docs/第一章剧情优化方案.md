## 第一章的戏剧主轴

**一群忘了昨晚的人，先凭痕迹辨认谁在救人，再凭彼此作证决定明天是否还能合作。** 第一场推演教玩家区分物理动作和人物动机；午间把同一方法用在证词与契约；黑板诗把推理方法转成玩家自己的处置判断；晚餐把这种判断落到互助、借物与分工。四个交接都应有明确的玩家行动和可见结果，允许同一时段内按可达性选路。

| 交接 | 玩家行动与反馈 | 推荐起点与复测终点 |
|---|---|---|
| 厨房：误会 → 可核对的救人过程 | 先给一个动作题（谁拖了谁、经过哪道门）。首件痕迹演示采样、返回、入账；其余证物区分本次推演必需与用于补强的线索。Huo、Shen、Su 的动作承担解释，避免逐件讲解重复同一结论。 | `kitchen-evidence` / `kitchen-reconstruction`；从实际取证走到推演，再以正常操作离开厨房。 |
| 跨区：各自为真 → 可共同验证的说法 | 雀儿的检修路线从甲区脱困，不改变丙、丁门禁。争执前把「亲眼所见」「隔窗/隔管所闻」「由契约措辞得出的解释」分开。允许先去已开放的线索点，也给回访和人物转场后的补问入口；午前汇合只等必要前提。 | `service-maintenance`、`cross-c-window`、`cross-d-pressure`、`cross-central`、`shaft-question`；优先用相同可达存档换序，再核对中翼交接。 |
| 黑板诗：查出真相 → 决定如何处置 | 提前抓现行、事后揭露、知情留白都保留。后续让选项由现场线索与时机支撑：半截蓝粉笔可引向蹲点，迟到后仍可查字迹高度与袖口。代管者的短评保留为人物动作与笑点。三个结果都给出下一处人物活动，但保留各自当场反应。 | 应从 `d1_poem_hint` 前的真实存档测选择；`poem-stakeout` / `poem-expose` / `poem-indulge` 只测预选结果。结束时看是否理解下一步，并实际走向下一处活动。 |
| 晚餐：共同劳动 → 次日开仓承诺 | 把借糖、修理和换药留给可见的递物与劳动；开仓分工前，在目标人物附近给明确的交谈提示。玩家确认分工后，留下能在第二天核对的承诺与责任人，再给休息入口。 | `dinner-dumpling` / `dinner-plan`；从分工对白走到 22:00 完成，再主动点 `Chapter 2`。`chapter-night` 仅检查已结算界面。 |

### 实现边界和顺序

1. **已接入：** 厨房近景说明采样完成后要返回房间；黑板诗三条结果统一由顾平章约玩家 15:30 到中翼看讲义，雀儿与代管者的英译保留完整的短句，避免尾词单独翻页。
2. **下一步：** 补黑板和晚餐的现场交互提示，建取自真实玩家路线的黑板诗选择前存档；从黑板对话结束实走到中翼，验证对白给出的时间与目标可用。把第二天开仓做成首个可核对的生活承诺兑现点。
3. **结构调整：** `DualEngine.process_beats()` 目前沿一个 `beat_cursor` 消费时间线；大部分跨房剧情自动换房，个别节拍在指定房间等待。先在同一时段内让可选调查独立开放，并保留原游玩路径与必要剧情检查点；确定两种真实行动顺序都能到达同一交接后，再逐处撤下自动换房。章末仍以 `d1_plan` 与现有完成条件收束。
4. **第二章衔接：** 第二天开仓与清点交接为第三天案件提供资源背景；阮清月耗时打谱后只选择一套满足前提的方案。缺页案抽页者的原文冲突保持待核。第四夜将危险告知、本人理解、实际到岗与救助分别落在世界状态上，耳罩路线保留关系代价与失败可能。
