# Chapter 1: Evaluation responsibilities

Each of the 11 story segments has one test ID, one revision and a continuous session. Its constituent scenes are evidence for that segment. One observer plays and assesses action, narrative flow and visual similarity; collectors measure the objective dimensions. The observer records their blind interpretation before viewing any story-revealing reference. Record gameplay and all seven dimensions on the same timeline. Gameplay, observations and technical records are in English.

| Dimension | Assessment source | Publication |
| --- | --- | --- |
| `fluidity` | Collector measures frame timing, FPS, warmup and concurrent load; observer notes perceived stutters. | Main agent submits collector result. |
| `text_density` | Collector automatically counts visible dialogue, prompts and conservatively counts unclassified visible text. Nameplates and single-key icons are excluded. It flags non-Latin script; Latin script alone does not establish English. No per-string observer confirmation is required. | Main agent submits collector result and rationale. |
| `action_sfx_integrity` | Observer scores visible physical action, contact, clipping, foot sliding, IK and visibility. This compatible field name now means action only. | Main agent submits observer score and evidence. |
| `audio_loudness` | Collector records the Master mix and measures LUFS and true peak; sound effects are captured along with other audio. Silence or interrupted recording is identified in the result. | Main agent submits measured result and evidence. |
| `blind_narrative_match` | Blind observer records their independent interpretation in English during the session. | After play, main agent compares the account to the canonical story and scores it. |
| `aesthetic_similarity` | The same gameplay observer compares same-session images with the assigned reference after recording the blind interpretation. | Main agent submits observer score and evidence. |
| `narrative_flow` | Blind observer scores guidance, pacing and transitions. | Main agent submits observer score and evidence. |

The standard blind flow is: the test agent uses MCP images and visible English UI to play, then records its independent interpretation from the visuals and gameplay, including uncertainties; internal scene, controller, navigation and story-state fields are hidden from the observer. after that account is complete, the main agent compares it with the true plot and scores narrative match. Before launch, prepare the collectors, single observer and visual reference. Keep sound, video, frame timings and text observations synchronized. Review key frames around story and dialogue changes, and retain continuous motion and sound around interactions. The main agent publishes the seven numbers together under the test ID, with reasons and evidence. A missing measurement receives a clearly labeled provisional zero and an explicit cause; mark the test incomplete and repeat it after repair.
