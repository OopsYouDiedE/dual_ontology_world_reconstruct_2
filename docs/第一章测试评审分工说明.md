# 第一章测试：观察员与主 Agent 的分工

本说明用于第一章的 11 个剧情分段测试。每个分段使用一个测试 ID；属于该分段的多个场景在同一实例、同一源码版本和连续采集时间线上完成。25 个场景是分段内的证据明细。

测试中的游戏语言、观察员记录和技术证据使用英文。本说明以中文汇报分工。观察员在测试前不要阅读剧情原文、标准答案或会泄露剧情的资料。

## 七项评分由谁负责

| 评分项 | 观察员负责 | 主 Agent 负责 |
| --- | --- | --- |
| `fluidity` 游戏流畅度 | 操作游戏，实时记录自己察觉到的卡顿、动作和发生时间。 | 根据同次测试的逐帧时间数据计算 FPS、P95/P99 和超过 33.3 ms 的稳态帧；标明并发负载，并按量表结算。冷启动和切场景后的前 1.5 秒单独记录。 |
| `text_density` 文字密度与英文 | 对当前实际可见的文字标注用途，并确认是否为英文；及时指出过长、未翻译或无法判断的文字。 | 使用同次会话的可见文字变化记录，统计同时显示的台词和交互提示的单词数、字符数，排除量表规定的姓名牌和单键图标；结合观察员标注给分。 |
| `action_sfx_integrity` 动作、贴花与音效 | 在游玩时记录动作、接触、贴花、镜头遮挡和音效体验；指出具体缺陷、动作及时间，按量表提出评分。音频无法实际感知时明确写出。 | 核对同一时间段的画面、录音和音效触发记录，汇总观察员的评分与证据。触发记录说明程序调度了音效；录音和播放情况用于核查实际输出。 |
| `audio_loudness` 音频响度 | 在察觉声音异常时记录发生时间和场景；无须转写语音。 | 从同次测试的原始音频计算综合响度 LUFS 和真峰值 dBTP，检查背景声、采集丢帧和音频路由，再按量表给分。 |
| `blind_narrative_match` 盲测剧情理解 | 不看标准剧情，边玩边用英文记录自己看到的动作、听到或通过可用渠道感知到的声音、对白和对事件的理解。保留不确定之处。 | 等观察员完成该段后，将同次盲测记录与标准剧情逐项比较，给出对应、遗漏、误判和评分；不得先向观察员透露答案。 |
| `aesthetic_similarity` 画面参考相似度 | 记录具有代表性的时刻、镜头和显著画面问题。盲测观察期间维持剧情隔离。 | 将同次测试的对应画面与该场景事先准备的参考图比较，说明构图、光线、材质和可读性差异，并给出有证据的评分。 |
| `narrative_flow` 叙事节奏与连贯性 | 从独立玩家视角记录引导是否清晰、等待或卡住的位置、转场是否自然，并按量表提出评分。 | 核对该段的游玩时间线和完整覆盖情况，连同观察员理由发布；缺少完整过程时写明未覆盖的阶段。 |

## 时间顺序与回传内容

1. **启动前，主 Agent 准备。** 固定并记录源码版本、测试 ID、分段和场景顺序；检查英文环境、参考图、性能／文字／音频／画面采集、观察员及其可用的观察方式。告知观察员操作规则和目标分段，不提供剧情答案。观察员确认自己实际能接收的画面、声音和视频方式。
2. **测试中，观察员连续操作和记录。** 从该分段的场景或检查点进入，通过项目 MCP 操作。每次有关键动作、对白、剧情理解变化、明显声音或卡点时，用英文及时记录测试 ID、场景、时间、实际观察和不确定之处；对可见文字完成必要分类。观察员同时形成动作／音效和节奏的评审意见。多个场景按计划在同一会话内切换。
3. **测试结束时，观察员向主 Agent 返回。** 返回同次会话的操作与观察记录、对剧情的原始推测、文字分类、动作／音效及节奏评分和理由、各场景完成状态、卡点，以及对应时间和证据。无法感知的声音或错过的片段应直接标明；未见到的内容不补写。
4. **主 Agent 结算并发布。** 读取同次测试的性能、文字、画面和音频证据，核对观察员结果和参考图；完成盲测剧情与标准剧情的对照。使用一个测试 ID 一次发布七项数值、各项理由、证据链接及具体失败或缺测原因。不得从其他测试或版本借分；缺测留空，实测失败按证据给失败分。

## 视频、关键帧与逐帧数据

同一次测试应保留带时间戳的画面与原始音频，使其可以合成为同步视频，并与观察记录对应。视频可供评审核查完整过程；上传的接收端和实际评审方式需要事先确定。当前项目 MCP 可返回画面和音频片段，观察员是否能够在其工具环境中播放或理解音频，需要在启动前实际确认。

剧情理解与参考图对照可以优先查看场景切换、交互、对白变化和剧情进展附近的关键帧；人物运动、镜头过渡与音效则保留变化前后的连续片段。模型不需要逐张阅读所有画面。性能依然逐帧记录时间；文字采集逐帧检查可见状态，只在状态变化时写入记录，以免遗漏短暂出现的提示。

视频、关键帧和指标都必须来自同一测试及时间线。测试期间需要完成的观察与评判应同步进行；盲测理解与标准剧情的比较在该段游玩后进行。

## 当前进度

截至本说明编写时，本轮第一章尚未开始实际游玩，因此七项均没有本轮实测分数。代码已具备流畅度和响度的自动计算路径；文字项具备自动计数与观察员分类路径；其余四项依赖观察员或主 Agent 对同次证据作评审。视频导出和实际播放评审方式仍在准备，真实 Godot 会话中的采集和结算效果仍待验证。
