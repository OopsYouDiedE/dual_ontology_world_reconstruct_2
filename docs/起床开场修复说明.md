# 起床开场修复说明（第一幕 · R05 床上醒来）

补丁作者记录的验证环境：Godot 4.7.2-stable（标准版）+ Xvfb + Mesa llvmpipe（无 GPU，OpenGL 兼容渲染）。
入口：`DualWorldMain.tscn` → `WakeOpening.gd`。作者使用独立工具补丁中的 `capture_opening.gd` 以 `--write-movie` 固定帧率录制并抽帧。

## 实测发现

| 现象 | 实测原因 |
| --- | --- |
| 躺在床上像「蜷成一团」，脸朝下 | 躺姿来自 KayKit `Lie_Idle`，它本身是**侧卧蜷缩**（左肩 y=0.10，右肩 y=0.58，两肩上下错开）；重定向到 Q 版小人（头占 28% 身高，躯干仅约 0.19m）后更挤 |
| 「撑起上身」看不出来 | `WakeModifier3D` 只绕 Spine 一根骨转一次，要把侧卧体硬转成坐姿，轴向和弯折位置都不对 |
| 起床动作和前面衔接不上 | `Lie_StandUp` 也以侧卧为起点 |
| 模型绑定本身是否有问题 | **没有**。`model_06.glb`：847 顶点 / 968 三角形，65 骨骼，权重全部归一，无零权重顶点；bind pose 与骨骼静止姿态误差 < 3e-6，逆绑定矩阵与静止全局一致 |

## 修改

- `scenes/components/characters/WakePoseLibrary.gd`（新）：从骨骼静止姿态求「前 / 上 / 左」坐标系，在角色坐标系里逐关节摆姿并烘焙成动画。
  - `wake/lie` 仰卧呼吸（循环）
  - `wake/getup`、`wake/getup_r` 撑坐 → 转身腿垂床沿 → 前倾起身 → 站定回身（左 / 右侧下床）
- `ProceduralFigure.gd`：仅侦探生成 `wake/*`；`lie` / `lie_stand_up` / `lie_stand_up_r` 优先使用；新增 `feet_low_y()` 供下床落脚。其他人物继续使用 KayKit 片段，不受影响。
- `WakeModifier3D.gd`：撑坐的弯折分摊到 Spine / Spine1 / Spine2（4 : 3.5 : 2.5）。
- `DualWorldMain.gd`：按出口方向选左 / 右侧下床；根节点分段运动（原地撑坐 → 挪到床沿 → 腿垂下脚落地 → 走出床边），脚落地由骨骼最低点校正，身体最多陷入床垫 0.16m。
- 合入时修正床沿位移方向：左右符号只用于目标床沿坐标，位移沿床的局部横轴计算，确保右侧下床时先移向右侧床沿。
- `0002-test-tools-capture-and-pose-sheets.patch` 包含录制、姿态截图及骨骼检查工具，按项目清理测试脚本的要求排除。

## 补丁作者记录的验证结果

开场时间线：黑场淡入 → 仰卧 → 撑坐 → 张望 → 台词 → 坐床沿 → 起身 → 自由操作，起床后落点仍为 `(4.95, 1.65)`；自由阶段没有右侧大 UI，WASD 移动，靠近物件出现「E · 查看」，互动弹出台词。

## 仍待处理

- 手部、脚踝没有细节动作（模型手指权重只用了一半关节，手是整块）。
- 起床时手没有撑在床沿，只是自然下垂；需要的话可在 `GETUP_POSES` 里加入前臂姿态。
- 房间里的发光标记圈在床上仍会显示在人物脚下。
