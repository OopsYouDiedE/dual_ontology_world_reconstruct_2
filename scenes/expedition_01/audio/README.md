# Expedition 01 · recording credits

All audio in this directory comes from recordings. Clips are cropped, level-matched and converted to 44.1 kHz mono Ogg Vorbis. Some cues layer recordings or use EQ, pitch changes and short echo. The clocks and bells are recordings of mechanical devices. There is no separate instrumental score or recorded dialogue.
