# ArchBuilder · Structure Lab 结构生成与实测

在 ArchBuilder 顶栏点 **Structure Lab**，或在 Godot 里打开同目录 `StructureLab.tscn`，按 F6。左侧是平面输入，右侧是用同一份求解结果生成的 Godot 现场。示例是两层 L 形建筑。右键拖动旋转，滚轮缩放。

## 第一次试画

1. 选 Ground → Hall → Paint room，在左侧空白区拖出两格。鼠标位置向下取整到所在的 4.2 m 开间；矩形笔刷包含起止两格，四层共用同一组轴线。
2. 保持 Hall，把 Room group 从 1 改为 2，在第一间旁画一格。两组之间出现一堵隔墙和一个门洞；改回 1 并重画该格，隔墙消失。改成 Laboratory 可比较隔墙两侧饰面。
3. 切到 Level 2，在相同位置画上层。回到 Ground，选 U stair up 点一格，再切上层看楼板留洞。Service shaft up 在连续且没有其他井占位的楼层向上延伸。
4. 底栏最后一栏依次选 **Slabs → Frame → Walls → Detail → Full**。每一档在前一档上继续装配：先看板洞，再看柱梁、开口墙身、线脚扶手与铺装，最后看可操作件。关闭 Cutaway 可看屋顶；检查门、挂点与导航请选 Full。
5. 底栏选 Columns 和轴号，填 Pin ΔX / ΔZ 后点 Pin / update，再扩建相邻开间，观察整根柱轴及相连的梁。Doors 可换门扇，Lights 可隐藏灯；Clear override 恢复生成值。Save / Load 保存绘图和覆写到 `user://academy-structure-v1.json`。运行时开门、阀门状态在重建后重置。
6. 选择 Doors → Operate，检查门扇、声损和导航链接。Audit panels 从眼高发物理射线；Bake navigation 对当前可见部分烘焙导航，检查整栋时先关闭 Cutaway。Auto repair 关闭后可以和修复模式对照；Diagnostics 中同时包含成功修复和需要处理的条目。New from seed 重新生成平面；Apply 保留绘图，只应用种子。

## 从输入到构件：按工序查看

|结构|生成步骤与定位规则|
|---|---|
|房间与共享墙|按楼层记录格地址与房间组 → 检查四邻 → 同组去墙，异组按轴线键只登记一次 → 用门洞左右墙垛和上部过梁构造实体 → 两侧分别用各自房型材质覆面。|
|楼板与梯井|取下一层有效井位 → 把矩形板拆成围绕洞口的四条板带 → 洞边立护栏，出口保留 → 无洞的大厅和实验室开间按 4×4 方格交替铺面。|
|柱、梁与藻井|每个开间登记四角柱键和四条梁轴 → 合并共用键 → 将轴覆写同时用于柱和两端梁节点 → 按两节点差求梁长与朝向 → 无梯井的指定房型在梁下生成四边藻井框。|
|直返梯、螺旋梯与立管|U 梯把 18 级平分到两个相反坡向，中间加平台；螺旋梯按每圈 14 级布置踏板。沿踏板外缘取扶手路径，间隔插柱，截面扫掠成扶手。竖井使用上下层同一平面地址，逐层生成管段，阀门共用立管网络键。|
|门窗与挂点|共享墙和入口设贯通门；外窗在窗台至过梁之间扣空并嵌玻璃和竖棂。门铰放置在左梃，生成扇叶、声学端口、导航链接；面板在门侧净墙处取 1.60 m 标高，记录目标门 ID。泵房同组气闸只允许开启其中一道。|
|护墙、券石与壁龛|从门窗边到柱端求可用墙长 → 按约 0.62 m 等分嵌板 → 上下两道线脚沿路径扫掠。装饰拱按 11 个角区间建立内外圆环扇面，再沿深度封边。泵房壁龛单独切去墙垛中央矩形；深度不足时在外侧补背衬与侧壁。|
|屋面、天沟与穹顶|筛出上方无楼板的开间 → 提取同高屋面外轮廓 → 用到轮廓的距离求中心与八个周边采样点高度 → 扇形三角化 → 用共边两侧面片的法向判别低谷，沿谷绘槽。天文台以环带和极点造穹顶，再把底圈接到开间周边采样点。|
|设施、照明与渲染|坡道和梯井净空以开间排除 → 其他指定墙段按种子与房型选架、桌或阀站 → 墙脚加局部污迹。挂点产生真实灯；同房组连通区派生反射探针及混响区。静态三角形按开间和材质合批，投影 UV 采用米制坐标；穹顶传入平滑法线，平面保持硬边，大表面生成 LOD。|
|碰撞与寻路|用实体三角面派生物理形状；位 1 管移动、2 管视线、4 管交互、8 管声学，再用独立位 16 筛选静态可烘焙碰撞。玻璃和花格门挡人，视线射线可穿过。静态导航在门槛断开，动态链接随门开闭；木门关闭 24 dB、铁艺门 6 dB、开启 2 dB，是测试参数。|

## 当前适用范围

平面支持 12×12 正交开间、四层、六种房型。造型和吸附以开间为单位；自由角墙、任意斜屋面的精确交线、逐道风管布线和全套历史构件仍需扩展。编辑时重算整栋，通过稳定 ID 重放覆写。声学图供查询；正式游戏的听觉 AI 与房牌生成入口尚未接入。屋面接缝目前按几何规则拼合，尚无逐种子的漏光验收。

## 回归入口

Godot 4.7.2 .NET 在仓库根目录运行 `--headless --path . --script res://tools/building_construction/tests/building_solver_test.gd`。既有组件库另由 `production_pipeline_test.gd` 检查；组件库可用的配方数量与本生成器实际自动布置的构件数量分别统计。
