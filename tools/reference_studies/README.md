# Codec Drift / 影像与声音小样

一段 45.57 秒的独立参考练习：方形镜头、模拟编解码损坏和原创电子配乐。参考为 Bilibili `BV11YqgBcEQo`。脚本从种子生成所有画面和声音，运行时无需下载视频、音乐、字体或其他素材。它不改动 Godot 主线、资源和存档。

## 本地生成

依赖：Python 3.10+、NumPy、SciPy、OpenCV（`opencv-python`），以及 PATH 上带 `libx264` 和 AAC 编码器的 FFmpeg。在项目根目录运行：

```powershell
python tools/reference_studies/codec_drift.py --output artifacts/references/codec_drift
```

输出 `codec_drift.mp4`（480×480 / 30 fps / 立体声）和 `codec_drift_score.wav`（48 kHz 立体声）。默认种子固定，`--seed` 可以更换林地纹理、漂浮颗粒、故障形状和合成器噪声。视频包含高饱和故障块和快速剪辑。

## 视听结构

| 秒 | 镜头 | 声音 |
| --- | --- | --- |
| 0–8.20 | 低清近摄切入林间，绿色块在地表成片堆积 | 低音滑落入约 180 BPM 的碎拍，编排亦可按 90 BPM 半拍感理解 |
| 8.20–21.32 | 水面纵向拖列，擦过树皮，鱼被冻住的旧帧打碎 | 踢鼓、饱和次低音、偏左右交错的金属脉冲；临近剪辑点加入断裂噪声 |
| 21.32–28.44 | 深紫红和冷蓝黄的两组发光微观形体 | 撤掉鼓和低音，留下带音高的短脉冲和分散的回声 |
| 28.44–38.31 | 显像管、眼睛、桌面和压缩色块硬切 | 低频和打击声回流，锯齿噪声把声场压窄 |
| 38.31–45.57 | 电梯按钮、楼层从 22 降至 18，切黑 | 五个楼层节点分别触发短铃、踢鼓与向下滑动的次低音 |

在 `codec_drift.py` 的 `TIMECUTS` 可改镜头切点。`Study.contaminate` 用运动差和稀疏缓存更新选择旧画面的大块区域，依镜头做染色、读列拉伸、条带移位和色通道失步。`codec_drift_score.py` 包含鼓、低音、调频脉冲和立体延时，全部直接合成。
